# 自作部品ライブラリの設計

取り込んだ STEP のアセンブリなどに付けたアクチュエータ・センサー・スクリプトを、形状と一緒に「自作部品」として保存し、標準部品と同じ「部品ライブラリ」から何個でも置けるようにする。

## 層の分け方

| 層 | 場所 | 中身 |
| --- | --- | --- |
| ドメイン | `model.rs` の `Node::custom_part` (`CustomInstance`) | 置いた自作部品のしるし。部品名・名前の頭・公開パラメータ。ノードに持つので、保存・元に戻す・形状の差し替えはほかの設定と同じに扱われる |
| ユースケース | `custom_part/param.rs` | 公開パラメータ (`ParamTarget`: ストローク・動作時間・可動範囲の下限 / 上限・センサーの検出距離) の読み書きと候補の列挙 |
| ユースケース | `custom_part/place.rs` | 部品をモデルとタイミングチャートに置く。名前の頭を付け、アクチュエータ・センサーの id を付け替える |
| アダプター | `custom_part/file.rs` | `part.cadpart` の JSON、ライブラリのフォルダへの保存と一覧 |
| UI | `custom_part/mod.rs`・`ui.rs` | ライブラリの Resource、読み込みのスレッド、保存のウィンドウ、パレットとプロパティ欄 |

## 保存するもの

`build` は、選んだノード (`root`) 以下と、次のアクチュエータ・センサーを集める。

- アクチュエータ: 動かす部品 (`parts`) のどれかが `root` 以下にあるもの。`parts` と `mounted_on` は部品の中にあるものだけ残す
- センサー: 集めたアクチュエータに載っているもの、またはどこにも載らず `root` の外接箱 (1% の余裕つき) の中にあるもの

木は `ProjectFile::from_subtree` で `.cadsim` と同じ形にする。一番上の位置は原点にし、ワールドでの回転は残す。
タイミングチャートの軸は X / Y / Z の固定なので、置くときは平行移動だけにする (回転させると軸が合わなくなるため)。
ピボットとセンサーの位置は、一番上の原点から見た座標で書く。部品は「最上位から順にたどる子の番号」で書き、先頭は部品の一番上を表す 0。

置いた自作部品をもう一度保存するときは、名前の頭を外して保存する。

## ファイル

ライブラリは設定ファイルと同じ場所の `parts` フォルダ (Linux なら `~/.config/cadsim/parts`、Windows なら `%APPDATA%\cadsim\parts`、Mac なら `~/Library/Application Support/cadsim/parts`)。
部品ごとに `<部品名>/part.cadpart` を作り、取り込んだ STEP などは同じフォルダに写して相対パスで指す (別のフォルダの同じ名前のファイルは頭に番号を付けて分ける)。
部品名の `/ \ : * ? " < > |` はフォルダ名では `_` にする。同じ名前の部品は置き換える。

```json
{
  "format_version": 1,
  "name": "プッシャー",
  "category": "治具",
  "description": "押し出し用",
  "params": [
    { "label": "ストローク", "target": { "type": "Stroke", "actuator": 1 }, "value": 30.0 }
  ],
  "project": { "format_version": …, "unit": "mm", "step_files": […], "nodes": […], "chart": {…} }
}
```

`project` は `.cadsim` と同じ形 (docs/project-file.md) で、読むときも `ProjectFile::from_json` で確かめる。ステップは持たない。
`params` の id は `project.chart` の中の id。アプリより新しい `format_version` は読まない。

## 置くとき

1. パレットの `+` かドラッグで `CustomLibrary::request_place` を呼ぶ。STEP の読み込みが重いので、別スレッドで `part.cadpart` を読み、`LoadedProject::from_file` で形状まで読む
2. `receive_placements` (Update) が結果を受け取り、`place` でモデルに足す。位置は標準部品と同じく 10 mm 刻みに丸める
3. `place` は同じ部品がいくつ置いてあるかを数えて `<部品名> <番号>` を付け、アクチュエータ・センサーの名前の頭を `<部品名> <番号>/` にする。id は `add_actuator` / `add_sensor` で新しく取り、`mounted_on` と公開パラメータを付け替える
4. 入れ子になった自作部品の名前の頭は、外側の頭を前に足す
5. 公開パラメータの既定値をチャートに書き、一番上のノードに `CustomInstance` を付けて、履歴に「追加」として積む

公開パラメータの値はタイミングチャートの項目そのものなので、プロパティ欄はチャートの今の値を表示し、変えたらチャートに書く (チャートの変更として元に戻せる)。

## スクリプトから見た名前

自作部品の中のスクリプトは、名前の頭を省いて自分の部品の I/O・センサー・関節を指せる (docs/scripting.md の「名前の解決」)。同じ部品を何個置いても、同じスクリプトでそれぞれの部品を動かせる。
