# 複数人でのレビュー

離れた人どうしが同じプロジェクトを開き、互いの視点・指している場所・選んだ部品・チャットを見せ合う機能のしくみです。
使い方は README の「離れた人と同じ工場をレビューする」を見てください。

## 全体の形

```text
  参加者 A ──┐                       ┌── 参加者 B
  (TCP)      │                       │   (TCP)
             ▼                       ▼
        ┌────────────── ホストのアプリ ──────────────┐
        │ 待ち受けスレッド → 配り役スレッド (Hub)     │
        │                     ▲    │                 │
        │       ホストの画面 ──┘    └─→ ホストの画面  │
        └─────────────────────────────────────────────┘
```

- 1人がホストになって TCP で待ち受け、ほかの人がつなぐ (星形)。参加者どうしは直接つながない。
- ホストは届いたメッセージを、送り主以外の全員に配る。ホスト自身の画面も番号 0 の参加者として、同じ配り役とチャンネル越しにやり取りする。
- 3D のモデル (STEP など) は送らない。全員が同じプロジェクトを手元で開いておき、視点・座標・部品の道順だけをやり取りする。
  参加したときにホストのプロジェクト名を受け取り、違うものを開いていればパネルに注意を出す。

## 層の分け方

| 層 | 場所 | 中身 |
| --- | --- | --- |
| ドメイン | `cadsim_core::review` | メッセージの型 (`Message`)、配り役 (`Hub`)、自分の画面から見た相手の様子 (`ReviewSession`)、送る回数の抑え方 (`SendThrottle`)、配置の変更の見つけ方 (`PlacementTracker`)、視点と注視点カメラの角度の変換 (`orbit_angles`) |
| アダプター | `cadsim_io::review` | 1 行の JSON への変換 (`wire`)、TCP の待ち受け・接続とスレッド (`net` の `ReviewLink`) |
| UI | `src/review/` | `mod.rs` (入力を集めて送り、届いたものをカメラとモデルに写す Bevy のシステム)、`view.rs` (アバター・指さし・印・枠・名札)、`panel.rs` (パネル) |

`Hub` と `ReviewSession` は通信から切り離してあり、「誰から何が届いたか」を渡すと「誰に何を送るか」「画面で何をするか」を返すだけなので、Bevy もソケットもなしに単体テストできる。

## 通信の取り決め

- TCP の上に、UTF-8 の JSON を 1 行 1 メッセージで送る。1 行は 64 KiB まで。超えた相手とは切る。
- 種類は `t` に書く。読めない行・知らない種類は飛ばす。NaN や無限大の座標は受け取らない。
- 既定のポートは 47800。取り決めの版 (`PROTOCOL_VERSION`) が違う相手は断る。

| `t` | 向き | 中身 |
| --- | --- | --- |
| `hello` | 参加者 → ホスト | 版・名前・合言葉・開いているプロジェクト名。つないで最初に送る |
| `welcome` | ホスト → 参加者 | 自分の番号・ホストのプロジェクト名・名簿 (番号・名前・色) |
| `rejected` | ホスト → 参加者 | 断った理由 (合言葉違い・版違い)。この後ホストが切る |
| `joined` / `left` | ホスト → 全員 | 誰かが入った・抜けた |
| `view` | 全員 | カメラの位置 `eye`・注視点 `focus`・平行投影か |
| `pointer` | 全員 | マウスが指している 3D の点 (部品に当たらなければ床 y = 0)。3D ビューの外なら `null` |
| `ping` | 全員 | 「ここを見て」の印の位置 |
| `select` | 全員 | 選んだ部品のツリーの道順 (`"組立 / 部品"`)。選んでいなければ `null` |
| `chat` | 全員 | チャット (500 文字まで) |
| `summon` | 全員 | 「みんなを自分の視点へ呼ぶ」。受け取った人のカメラがこの視点へ動く |
| `placement` | 全員 | 部品の道順と、親から見た配置の 4×4 行列 (列優先の 16 個) |

例:

```json
{"t":"hello","version":1,"name":"佐藤","passphrase":"line1","project":"demo_line.cadsim"}
{"t":"view","id":2,"pose":{"eye":[3.1,2.0,5.4],"focus":[0.0,0.5,0.0],"ortho":false}}
```

## 配るときの規則 (`Hub`)

- 名乗る (`hello`) までは名簿に入れない。名乗る前にほかのメッセージを送ってきた相手は切る。
- 参加者から届いたメッセージの `id` は、送り主の番号で書き直してから配る。ほかの人になりすますことはできない。
- 名乗り・迎え・入退室のメッセージを参加者が送ってきても配らない。空のチャットも配らない。
- 各自の最新の視点と選択を覚えておき、後から入った人に `welcome` の直後に送る。入ってすぐに全員のアバターが見える。
- 書き込みが 3 秒詰まった相手は切り、ほかの人に `left` を配る。

## 送る回数

視点とマウスの位置は毎フレーム変わるので、`SendThrottle` で 1 秒に 20 回までにし、最後に送った値から変わったときだけ送る。
「最後に送った値」と比べるので、動きが止まった直後の値も次の機会に必ず届く。
視点は注視点までの距離の 0.1% より小さい動きは送らない。

## 視点を追う・呼ぶ

受け取った視点 (`eye`・`focus`) を、注視点を回るカメラの yaw・pitch・距離に直し (`orbit_angles`)、
`OrbitCamera::fly_to` で少しアニメーションさせて合わせる。届く間隔 (1/20 秒) の間もなめらかに動く。
追いかけ中に右・中ボタン・Alt + 左・ホイールでカメラを触ると、追うのをやめる。

## 配置の共有

「配置の変更も共有する」をオンにした人どうしで、部品の配置 (`Node::placement`) を受け渡す。

- 部品は番号ではなくツリーの道順で指す。同じプロジェクトを開いていれば、読み込みの順で番号がずれても同じ部品に当たる。
  道順が同じ部品が 2 つ以上あるときは、どれか分からないので送りも受け取りもしない。
- モデルが変わったとき (1 秒に 20 回まで) に全部品の配置を前に見た配置と比べ、変わったものだけ送る (`PlacementTracker`)。
  オンにした直後とつないだ直後は、今の配置を覚えるだけで送らない。
- 受け取った配置を写したら、その値を覚えておき、送り返さない。
- 同じ部品を 2 人が同時に動かすと、後から届いたほうが勝つ。

## 安全のために

- 合言葉はホストが決め、合わない相手は断る。通信は暗号化していないので、社外とつなぐときは VPN の中で使うのを勧める。
- 受け取るのは座標・名前・文字列だけで、ファイルやスクリプトは受け取らない。配置の共有はオンにした人だけが受け取る。
- 1 行の長さに上限を設け、それを超えた相手とは切る。
