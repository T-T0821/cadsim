# シミュレーション結果の CSV 出力

タイミングチャートのサイクルタイムと、1サイクル動かしたときの干渉の結果を CSV に書き出せます。
Excel でそのまま開けるので、装置検討の資料やタクトの見直しに使えます。

## 書き出す

メニューの **ファイル → シミュレーション結果 (CSV)** を開き、どちらかを選んで保存先を決めます。
書き出しが終わると、画面下のステータスバーに保存先が出ます。

| メニュー | 書き出すもの |
| --- | --- |
| サイクルタイム… | ステップごとの開始・終了・所要時間と、そのステップで一番時間のかかる動作。最後の行がサイクルタイム |
| 干渉結果 (1サイクル分)… | チャートを最初から最後まで動かしながら調べた、干渉・接触・近接の時間帯 |

## サイクルタイムの表

| 列 | 内容 |
| --- | --- |
| ステップ / コメント | チャートのステップ番号と説明 |
| 開始[s] / 終了[s] / 所要時間[s] | サイクル開始からの時刻と、そのステップの長さ |
| 動作時間[s] / タイマー[s] | 一番遅い動作の時間と、動作完了後の待ち時間 |
| 最も長い動作 | そのステップの長さを決めているアクチュエータ。ここを速くするとサイクルタイムが縮みます |
| 動作 | そのステップの指令の一覧 |

## 干渉結果の表

同じ部品の組が同じ状態(干渉 / 接触 / 近接)だった時間帯を1行にまとめます。

| 列 | 内容 |
| --- | --- |
| 判定 | 干渉 / 接触 / 近接 |
| 部品A / 部品B | 組になった部品(ID も付きます) |
| 開始[s] / 終了[s] / 継続時間[s] | その状態だった時間帯 |
| 開始ステップ / 開始ステップのコメント / 終了ステップ | どのステップで起きたか |
| 最大干渉体積 / 最小クリアランス | 一番深く食い込んだときの体積、または一番近づいたときのすき間 |

- メニューの **干渉チェックの間隔**(初期値 0.02 秒)ごとに調べます。小さくすると時刻が正確になり、そのぶん時間がかかります。
- 許容差・警告値・体積を計算するかは、シミュレーションパネルの設定を使います。
- チャートが空のときは、いまの配置を1回だけ調べます。
