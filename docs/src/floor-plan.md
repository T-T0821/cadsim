# 平面図を床に敷く

工場の平面図(レイアウト図)を 3D ビューの床に敷いて、その上に設備を並べられます。
柱や通路、既存の設備の位置に合わせて置き場所を決めるときに使います。

## 敷ける図面

| 形式 | 読み込まれるもの | 縮尺 |
| --- | --- | --- |
| DXF(.dxf) | 線・ポリライン・円・円弧・楕円・スプライン・ブロック | 図面に単位が書いてあれば実寸で敷きます |
| PDF(.pdf) | 1ページ目の線と、いちばん大きな画像(スキャンした図面など) | 用紙の大きさで敷くので、縮尺合わせが必要です |
| 画像(.png / .jpg) | 画像そのもの | 幅が 10 m になる大きさで仮に敷くので、縮尺合わせが必要です |

DWG は直接読めません。CAD で DXF に保存し直してから開いてください。

## 敷きかた

1. **ファイル → 開く…**(**Ctrl + O**)で図面を選ぶか、ウィンドウにドラッグ&ドロップします。
2. 図面の左下が原点に来るように床(高さ 0)に敷かれ、画面左下に **平面図・点群** パネルが出ます。
3. 縮尺の分からない図面のときは、ステータスバーに「縮尺合わせで実寸に合わせてください」と出ます。下の手順で合わせてください。

敷いた図面はクリックしても選ばれないので、上に置いた設備の操作のじゃまになりません。

## 縮尺を合わせる

寸法の分かっている2点(柱の芯どうし、建屋の端から端など)を使います。

1. パネルの **📏 縮尺合わせ** を押します。
2. 図面上の1点目をクリックします。線の端の近くでは端に吸い付きます。
3. 2点目をクリックします。パネルに「いまの2点間」の長さが出ます。
4. **実際の距離** に本当の長さを入れて **適用** を押します。

適用するときに、次の2つも一緒にできます。

- **1点目 → 2点目 の向きを X 軸に合わせる**: 斜めに描かれた図面や、傾いてスキャンされた図面をまっすぐにします。
- **1点目を原点 (0, 0) に移す**: 基準にしたい柱などを原点に持ってきます。

2点目を選び直したいときは **Esc** で1点目からやり直せます。もう一度 **Esc** を押すか **やめる** で縮尺合わせを終えます。

## 位置や見え方を変える

パネルでは図面ごとに次を変えられます。

| 欄 | 内容 |
| --- | --- |
| 縮尺 | 図面の 1 がモデルの単位でいくつか |
| 原点 X / Z | 図面の原点を置く場所 |
| 回転 | 上から見た回転角(度) |
| 高さ (Y) | 敷く高さ。2階の床などに |
| 不透明度 | 薄くすると設備が見やすくなります |

👁 で表示 / 非表示、🗑 で図面を外せます。

## 保存

敷いた図面と縮尺・位置はプロジェクト(.cadsim)に保存されます。図面の中身は保存せず、開くときに元のファイルから読み直すので、**図面のファイルは移動や削除をしないでください。**
