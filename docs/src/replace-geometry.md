# 形状の差し替え

設計変更で STEP などを出し直したとき、取り込み済みのアセンブリの形状だけを新しい版に入れ替えます。
タイミングチャートのアクチュエータなど、部品に付けた設定は付け直す必要がありません。

## 手順

1. ツリーかビューで、差し替えたいアセンブリ(または部品)を選ぶ
2. メニューの「編集 → 形状を差し替え…」を押す
3. 新しい版のファイル(STEP / glTF / OBJ / STL / USD)を選ぶ

## どの部品が対応するか

- ツリーの上からの名前の並びが同じ部品は、同じ部品とみなします。
- 階層を移った部品も、名前がほかと重ならなければ対応します。
- 名前を付け直した部品も、製品名がほかと重ならなければ対応します。
- アセンブリ全体の置き場所は変わりません。

## 結果の確かめ方

差し替えが終わると「形状の差し替え」ウィンドウが出ます。

- **新しい形状に見つからなかったもの**: 古い形状のまま残しています。要らなければツリーから削除してください。
- **新しく加わったもの**: 動きの設定はまだ付いていません。

名前をクリックするとその部品が選ばれます。うまく対応しなかったときは Ctrl + Z で差し替える前に戻せます。
