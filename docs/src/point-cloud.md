# 点群を読み込む

3D スキャナーで測った既存の建屋や設備の点群を読み込み、新しく置く設備とぶつからないかを確かめられます。

## 読み込める形式

| 形式 | 補足 |
| --- | --- |
| PLY(.ply) | ASCII / バイナリ。色があれば色付きで表示します。単位と上向きの軸は **ファイル → OBJ / STL の単位** の設定に従います |
| LAS(.las)・LAZ(.laz) | 座標は m、Z 軸が上として読みます。圧縮された LAZ もそのまま開けます |
| E57(.e57) | 複数のスキャンが入っていればすべて読み、それぞれの位置に置きます |

**ファイル → 開く…** で選ぶか、ウィンドウにドラッグ&ドロップします。

## 点の間引きと表示

数億点の点群でもそのまま扱えるように、読み込むときに点を間引きます。

- 5 mm より近い点は1つにまとめます。
- それでも多いときは、全体で 300 万点に収まるまで間隔を広げます。
- 何点を何点にしたかは、ステータスバーとパネルに「1.2億 点 → 300万 点 (間隔 8 mm)」のように出ます。

表示するときは、カメラから遠い所ほど点を減らして描きます。パネルの **表示の細かさ** を大きくすると遠くまで細かく描きます(重くなります)。
色のない点群は、高さに応じて色を付けて描きます。

## 位置を合わせる

点群は床(高さ 0)の上に置かれます。パネルの **位置 X / Y / Z** と **回転** で、設備のモデルと合う位置に動かしてください。

## 点群との干渉を調べる

パネルの **点群との干渉** で、表示中の部品と点群の位置関係を調べます。

| 表示 | 意味 |
| --- | --- |
| 干渉 名前: 内側に N 点 | 部品の中に点群の点が入っている(ぶつかっている)。ビューに赤い × 印で出ます |
| 近接 名前: 距離 | 部品と点群のすき間が **近接の警告距離** より小さい。いちばん近い所を黄色い線で結びます |

**自動** にチェックを入れておくと、部品を動かすたびに調べ直します。外しているときは **今すぐチェック** を押してください。

## 保存

点群の場所・位置・間引きの設定はプロジェクトに保存され、開くときに元のファイルから読み直します。点群のファイルは移動や削除をしないでください。
