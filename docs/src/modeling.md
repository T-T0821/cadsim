# 円柱・押し出し・穴・ブーリアン

箱のほかに、簡単な形を plantwright の中で作れます。STEP をもらう前の仮の設備や、架台の穴あけなどに使えます。
**作成** メニューから選ぶと **モデリング** の画面が開きます。上のタブで切り替えられます。

## 円柱

**作成 → 円柱を追加…**。**半径** と **高さ** を入れて **円柱を追加** を押すと、床に立った円柱がほかの部品と重ならない場所に置かれます。

## 押し出し

**作成 → 押し出しで追加…**。上から見た形の頂点を `x, y` で並べ、`;` か改行で区切って入れます。y は上面図で上向き(奥、-Z 方向)です。
**高さ** を入れて **押し出して追加** を押すと、その形を上に押し出した部品ができます。

```text
0,0; 400,0; 400,200; 200,300; 0,200
```

頂点は時計回りでも反時計回りでもかまいません。

## 穴あけ

部品(箱か、ここで作った部品)を選ぶと、プロパティに **形を編集: 穴をあける** が出ます(作成 → 穴をあける… でも同じ)。押すと 3D ビューで穴を置く道具になります。

1. **面をクリック。** カーソルを乗せた面が光ります。クリックした所が穴の入口の中心になり、穴の向きはその面に垂直な軸(X / Y / Z のいちばん近いもの)になります。最初は貫通です。
2. **丸い点をドラッグ。** 入口の円の上の黄色い点をドラッグすると直径が変わります。
3. **底の点をドラッグ。** 軸の先の黄色い点を手前に引くと深さが決まり、部品の奥まで引き戻すと貫通に戻ります。
4. **Enter** (またはパネルの ✔ 穴をあける)で確定。**Esc** で置きかけの穴を取り消し、もう一度押すと道具をやめます。

Ctrl を押しながらドラッグすると、「ギズモのスナップ」の寸法の刻みにそろいます。モデリングパネルの穴あけタブで、直径と深さを数値でも直せます(深さ 0 で貫通)。別の面をクリックすると置き直せます。

## ブーリアン

**作成 → ブーリアン (和・差・積)…**。1つ目の部品を選んでから、画面で2つ目の部品と演算を選びます。

| 演算 | 結果 |
| --- | --- |
| 和 | 2つを合わせた形 |
| 差 | 1つ目から2つ目と重なる所を削った形 |
| 積 | 2つが重なっている所だけ |

結果は1つ目の部品に入り、2つ目の部品は消えます。

## 使える部品と注意

- 穴あけとブーリアンができるのは、箱と、この画面で作った部品だけです。STEP などから取り込んだ部品は使えません。
- 演算した箱は、ふつうの部品になります(寸法の欄やギズモで大きさを変えることはできなくなります)。
- どの操作も **Ctrl + Z** で元に戻せます。
- 作った形はプロジェクト(.plantwright)の中に保存されるので、元のファイルはありません。glTF・OBJ・STL などに書き出して他のソフトに渡せます。
