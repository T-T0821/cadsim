# 円柱・押し出し・穴・ブーリアン・断面・質量

箱のほかに、簡単な形を plantwright の中で作れます。STEP をもらう前の仮の設備や、架台の穴あけなどに使えます。
**作成** メニューから選ぶと **モデリング** の画面が開きます。上のタブで切り替えられます。

## 円柱

**作成 → 円柱を追加…**。**半径** と **高さ** を入れて **円柱を追加** を押すと、床に立った円柱がほかの部品と重ならない場所に置かれます。

## 押し出し

**作成 → 押し出しで追加…**(モデリングの「押し出し」タブ)。3D ビューで描くのがいちばん早い方法です。

1. **床に描いて押し出す** を押します(3D ビューの何もない所を右クリック → 床に描いて押し出す でも同じ)。
2. **床をクリック** して頂点を置いていきます。カーソルの横に、置こうとしている辺の長さが出ます。Esc で 1 つ戻ります。
3. **最初の点をクリック**(か Enter)で形が閉じ、上に押し出した形の下書きが出ます。
4. **上の黄色い点をドラッグ** して高さを決めます(Ctrl で「ギズモのスナップ」の刻みにそろいます)。頂点の点をドラッグすると形を直せます。パネルで高さを数値でも直せます。
5. **Enter**(またはパネルの ✔ 押し出す)で確定。部品ができて選ばれます。

数値で入れることもできます。上から見た形の頂点を `x, y` で並べ、`;` か改行で区切って入れます。y は上面図で上向き(奥、-Z 方向)です。
**高さ** を入れて **押し出して追加** を押すと、その形を上に押し出した部品ができます。

```text
0,0; 400,0; 400,200; 200,300; 0,200
```

頂点は時計回りでも反時計回りでもかまいません。

## 穴あけ

部品(箱か、ここで作った部品)を選ぶと、プロパティに **形を編集: 穴をあける** が出ます(作成 → 穴をあける… でも同じ)。押すと 3D ビューで穴を置く道具になります。

1. **面をクリック。** カーソルを乗せた面が光ります。クリックした所が穴の入口の中心になり、穴の向きはその面に垂直な軸(X / Y / Z のいちばん近いもの)になります。最初は貫通です。
2. **丸い点をドラッグ。** 入口の円の上の黄色い点をドラッグすると直径が変わります。
3. **底の点をドラッグ。** 軸の先の黄色い点を手前に引くと深さが決まり、部品の奥まで引き戻すと貫通に戻ります。
4. **Enter** (またはパネルの ✔ 穴をあける)で確定。**Esc** で置きかけの穴を取り消し、もう一度押すと道具をやめます。

Ctrl を押しながらドラッグすると、「ギズモのスナップ」の寸法の刻みにそろいます。モデリングパネルの穴あけタブで、直径と深さを数値でも直せます(深さ 0 で貫通)。別の面をクリックすると置き直せます。

## ブーリアン

**作成 → ブーリアン (和・差・積)…**。1つ目の部品を選んでから、画面で2つ目の部品と演算を選びます。

| 演算 | 結果 |
| --- | --- |
| 和 | 2つを合わせた形 |
| 差 | 1つ目から2つ目と重なる所を削った形 |
| 積 | 2つが重なっている所だけ |

結果は1つ目の部品に入り、2つ目の部品は消えます。

## あとから直す・消す(形の編集履歴)

穴をあけたりフィレットをかけたりした部品を選ぶと、プロパティに **形の編集履歴** が出ます。

| 行 | 中身 |
| --- | --- |
| 出発点 | 最初の形。箱から始めた部品なら「箱 100 × 40 × 100」と寸法が出て、X / Y / Z を直せます |
| 1. 穴 φ20 | そのあとの編集が順に並びます。直径・半径・厚みなどの数値を変えてドラッグを離す(か Enter)と、出発点からその形を作り直します |
| 🗑 | その編集だけを消します。あとの編集は残ります |

- フィレットや面取りの辺は、作り直すときに前の形からいちばん近い辺に当て直します。前の編集を大きく変えて辺が見つからなくなると、赤い字で理由が出て形は変わりません。
- 直した結果も **Ctrl + Z** で戻せます。
- 円柱や押し出しで作った部品は、最初の編集をかけたときの形が出発点になります。

## 質量と重心を見る

部品を選ぶと、プロパティの **質量・重心** に質量・体積・重心・慣性モーメント・表面積が出ます。3D ビューでは重心に紫の小さな球が出ます。
**材質** のドロップダウン(鉄・ステンレス・アルミ・真鍮・銅・樹脂・ゴムなど)を選ぶと、その密度で質量が計算し直されます。同じ値は物理演算の重さにも使われます。

アセンブリを選ぶと中の部品の合計になり、材質を選ぶと中の部品すべてがその材質になります。部品が 100 個を超えるアセンブリは **質量を計算** を押したときに計算します。
STEP から読み込んだ部品も対象です。面が欠けていて閉じていない部品は計算に入らず、名前が黄色で出ます。

## 断面で中を見る

プロパティの **調べる: 断面** を押すと、選んだ部品(何も選んでいなければモデル全体)の中心に平面が出て、切り口が赤い線で出ます。

1. **矢印の先をドラッグ。** 平面から出ている矢印の先の黄色い点をドラッグすると、平面が前後に動きます。Ctrl を押しながらだと寸法の刻みにそろいます。
2. **向きを変える。** プロパティの **X軸 / Y軸 / Z軸** でその軸に垂直な平面にし、**⇄ 反転** で矢印を逆向きにします。部品の面をクリックすると、その面に平行な平面になります。
3. **Esc**(または Enter・**断面を閉じる**)で閉じます。

プロパティの **位置** のスライダーでも動かせます。断面を出している間は、クリックで部品を選び直したりギズモを出したりしません。

## STEP を読み込んだときの形状の修復

STEP の形状にすき間があると、読み込みのときに自動で閉じます。直した部品があればステータスバーに「形状のすき間を ○ 件閉じました」と出て、押すたびに直した部品を選んで寄ります(「消す」で案内を消せます)。
直した部品はアセンブリツリーの名前の横に 🔧、直せなかった(閉じていない)部品には ⚠ が付き、プロパティにも説明が出ます。

閉じていない部品も表示・断面・干渉チェックには使えますが、質量は計算できません。元の CAD で「ソリッドとして書き出す」設定にすると直ることがあります。

## 使える部品と注意

- 穴あけとブーリアンができるのは、箱と、この画面で作った部品だけです。STEP などから取り込んだ部品は使えません。
- 演算した箱は、ふつうの部品になります(寸法の欄やギズモで大きさを変えることはできなくなります)。
- どの操作も **Ctrl + Z** で元に戻せます。
- 作った形はプロジェクト(.plantwright)の中に保存されるので、元のファイルはありません。glTF・OBJ・STL などに書き出して他のソフトに渡せます。
