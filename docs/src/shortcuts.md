# ショートカット一覧

メニューの **ヘルプ** でも同じ一覧を見られます。

## マウス

| 操作 | 内容 |
| --- | --- |
| 左クリック | 部品を選択(何もないところで選択解除) |
| ダブルクリック | その部品を画面いっぱいに表示 |
| 右クリック(動かさずに離す) | 部品のメニュー: 拡大 / これだけ表示 / 隠す / 親を選択 / 穴をあける / 削除。何もないところでは 全体を表示 / 等角ビュー / すべて表示 / 箱を追加 |
| カーソルを部品の上で止める | 部品の名前が出る |
| Alt + 左ドラッグ | オービット |
| 中ドラッグ | パン |
| ホイール / Alt + 右ドラッグ | ズーム |
| 右ドラッグ | 見回す |
| ギズモを左ドラッグ | 移動 / 回転 / 拡大縮小 |
| Ctrl + ギズモを左ドラッグ | スナップしながら操作 |
| ツリーの行をダブルクリック | その部品を拡大表示 |
| ツリーの行を右クリック | 選択を拡大 / これだけ表示 / 隠す / 削除 |

## キーボード

| キー | 内容 |
| --- | --- |
| W / E / R | 移動 / 回転 / 拡大縮小ギズモに切り替え |
| F / Home | 選択を拡大 / 全体を表示 |
| 1 / 3 / 7 / 0 | 正面 / 右側面 / 上面 / 等角ビュー |
| Ctrl + 1 / 3 / 7 | 背面 / 左側面 / 下面ビュー |
| 5 | 透視投影 / 平行投影を切り替え |
| H / Alt + H | 選択を隠す / すべて表示 |
| Esc | 選択を解除(計測中・寸法を置いている間・平面図の縮尺合わせ中・穴を置いている間は 1 点目の取り消し / 道具をやめる。部品の役割を付けている間は、その下書きを取り消す) |
| Enter | 穴あけの道具で、置いた穴を確定する。部品の役割を付けている間は、その役割を確定する |
| M | 距離計測モードの切り替え |
| Delete | 選択を削除 |
| Ctrl + Z | 元に戻す |
| Ctrl + Y / Ctrl + Shift + Z | やり直し |
| Ctrl + N | 新規プロジェクト |
| Ctrl + O | 開く(`.plantwright` は開き直し、STEP / glTF / OBJ / STL / USD は取り込み) |
| Ctrl + S / Ctrl + Shift + S | 保存 / 名前を付けて保存 |
| F1 | AI に聞く(使い方の質問)を開く / 閉じる |
| 右ボタン + W / A / S / D | 前後左右に移動 |
| 右ボタン + Q / E | 下降 / 上昇 |
| 右ボタン + Shift | 速く移動 |

一人称で歩いている間(🎥 ビュー → 🚶 一人称で歩く)は、次のキーになります。ギズモの W / E / R などのショートカットは止まります。

| キー | 動作 |
| --- | --- |
| W / S または ↑ / ↓ | 前へ / 後ろへ歩く |
| A / D | 左へ / 右へ横歩き |
| Shift を押しながら | 走る |
| 右ドラッグ / ← / → | 見回す / 向きを変える |
| Esc | 歩くのをやめる |
