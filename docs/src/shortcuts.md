# ショートカット一覧

## マウス

| 操作 | 内容 |
| --- | --- |
| 左クリック | 面を選択(何もないところで選択解除) |
| Alt + 左ドラッグ | オービット |
| 中ドラッグ | パン |
| ホイール / Alt + 右ドラッグ | ズーム |
| 右ドラッグ | 見回す |
| ギズモを左ドラッグ | 移動 / 回転 / 拡大縮小 |
| Ctrl + ギズモを左ドラッグ | スナップしながら操作 |

## キーボード

| キー | 内容 |
| --- | --- |
| W / E / R | 移動 / 回転 / 拡大縮小ギズモに切り替え |
| F | 選択中の部品にフォーカス |
| Delete | 選択中の部品を削除 |
| 右ボタン + W / A / S / D | 前後左右に移動 |
| 右ボタン + Q / E | 下降 / 上昇 |
| 右ボタン + Shift | 速く移動 |
