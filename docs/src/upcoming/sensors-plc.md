# センサー・シーケンサー(PLC)

> **開発中**: 光電センサー・近接センサーやシーケンサーを置く部分は、[標準部品ライブラリ](parts-library.md)と一緒に作っています。いまは [安全機器](../safety.md)(ライトカーテン・エリアセンサ・非常停止)で、人や AGV が入ったら止まるところまで確かめられます。

## できるようになること

- 光電センサーやリミットスイッチを置き、部品が来たら ON になるようにする
- シーケンサー(PLC)を配置し、センサーの入力からシリンダーやモーターを動かすロジックを組む
