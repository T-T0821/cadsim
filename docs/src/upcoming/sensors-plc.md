# シーケンサー(PLC)

> **予定**: ラダーなどの PLC のロジックを plantwright の中で組む機能は、まだ作りはじめていません。
>
> いまできること:
>
> - 光電・近接センサーとステップの開始条件(インターロック): [センサーとインターロック](../sensors.md)
> - 実機の PLC(Modbus TCP / OPC UA)か内蔵の模擬 PLC の出力でシリンダや軸を動かす: [PLC で設備を動かす](../plc.md)

## できるようになること

- シーケンサー(PLC)を配置し、センサーの入力からシリンダーやモーターを動かすロジックを組む
