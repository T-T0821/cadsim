# センサー・シーケンサー(PLC)

> **開発中**: 光電センサー・近接センサーやシーケンサーを置く部分は、[標準部品ライブラリ](parts-library.md)と一緒に作っています。
>
> いまできること:
>
> - 実機の PLC(Modbus TCP)か内蔵の模擬 PLC の出力でシリンダや軸を動かし、出端・戻端・現在位置を返す: [PLC で設備を動かす](../plc.md)
> - ライトカーテン・エリアセンサ・非常停止で、人や AGV が入ったら止める: [安全機器](../safety.md)

## できるようになること

- 光電センサーやリミットスイッチを置き、部品が来たら ON になるようにする
- シーケンサー(PLC)を配置し、センサーの入力からシリンダーやモーターを動かすロジックを組む
