# 各 CAD から STEP を書き出す

cadsim は SOLIDWORKS や CATIA などの CAD 独自のファイル(.sldprt / .sldasm / .ipt / .iam / .CATPart / .prt など)を直接は読めません。
設計した CAD で **STEP(.step / .stp)** に書き出してから開いてください。STEP は国際規格(ISO 10303)の形式で、ほとんどの CAD が書き出せます。

## 書き出すときのおすすめ設定

| 項目 | おすすめ | 理由 |
| --- | --- | --- |
| 規格(AP) | **AP242**、なければ **AP214** | 色とアセンブリの構成が入ります。AP203 は色が入らないことがあります |
| アセンブリ | 1つのファイルにまとめる | 部品ごとに別ファイルに分けると構成が読めません |
| 単位 | mm | cadsim はファイルに書かれた単位で開きます(mm / cm / m / inch) |
| 出力するもの | ソリッドとサーフェス | ワイヤーフレームやスケッチは読み込みません |

## CAD ごとの書き出しかた

メニューの名前は版や言語の設定で少し違うことがあります。見つからないときは、各 CAD のヘルプで「STEP 書き出し」を探してください。

| CAD | 手順 | 設定の場所 |
| --- | --- | --- |
| SOLIDWORKS | **ファイル → 名前を付けて保存**、ファイルの種類で **STEP AP214** か **STEP AP242** を選ぶ | 同じ画面の **オプション…** |
| Autodesk Inventor | **ファイル → 書き出し → CAD 形式**、ファイルの種類で **STEP ファイル (*.stp)** を選ぶ | 同じ画面の **オプション…** で「アプリケーション プロトコル」を 214 か 242 に |
| Autodesk Fusion | **ファイル → エクスポート**、タイプで **STEP ファイル (*.stp)** を選ぶ | — |
| CATIA V5 / 3DEXPERIENCE | **ファイル → 別名保存**(3DEXPERIENCE は **エクスポート**)、形式で **stp** を選ぶ | **ツール → オプション → 一般 → 互換性 → STEP** で AP214 / AP242 |
| Siemens NX | **ファイル → エクスポート → STEP** | 書き出しの画面で AP214 / AP242 を選ぶ |
| Creo Parametric | **ファイル → 名前を付けて保存 → コピーを保存**、タイプで **STEP (*.stp)** を選ぶ | **OK** の後に出る書き出し設定 |
| Solid Edge | **名前を付けて保存**、ファイルの種類で **STEP ドキュメント (*.stp)** を選ぶ | 同じ画面の **オプション** |
| iCAD SX / iCAD V8 | 外部ファイルの出力(STEP)を選ぶ | 出力の画面で AP214 と、色を出力する設定を選ぶ |
| Onshape | パーツスタジオかアセンブリのタブを右クリック → **エクスポート**、形式で **STEP** を選ぶ | 同じ画面 |
| FreeCAD | 部品を選んで **ファイル → エクスポート**、ファイルの種類で **STEP with colors** を選ぶ | **編集 → 設定 → インポート/エクスポート → STEP** |

設備メーカーに図面データをお願いするときも、「STEP(AP214 か AP242)のアセンブリ 1 ファイルで」と伝えるとそのまま使えます。

## うまく読めないとき

| 症状 | 確かめること |
| --- | --- |
| 色が付かない | AP203 で書き出していないか。AP214 / AP242 で書き出し直す |
| ツリーが1段だけになる | アセンブリを「1つのファイル」で書き出したか。部品ごとの別ファイルになっていないか |
| 大きさが 1000 倍 / 1/1000 になる | 書き出しの単位の設定。ステータスバーの単位表示も見る |
| 一部の部品が出ない | ステータスバーに「読めなかった形状 N 件」と出ていないか。CAD 側で「ソリッドとして出力」「サーフェスを縫い合わせる」を選んで書き出し直す |
| とても重い | 細かいねじやばねなど、レイアウトに要らない部品を CAD 側で外して書き出す |

2D の平面図は STEP ではなく DXF で受け取ってください([平面図を床に敷く](floor-plan.md))。DWG は CAD で DXF に保存し直してから開きます。
