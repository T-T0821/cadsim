# 部品スクリプト

タイミングチャートのステップでは書きにくい動き(条件で分ける、繰り返す、部品どうしで合図を送る)を、部品ごとのスクリプトで書けます。
スクリプトは [Rhai](https://rhai.rs/book/) という、Rust や JavaScript に似た書き方の言語です。

## スクリプトを付ける

1. ツリーかビューで部品(またはアセンブリ)を選ぶ
2. 右のプロパティの「スクリプト」を開き、**スクリプトを付ける** を押す
3. ひな形が入るので書き換える。書き方を間違えると、欄の下に赤字で表示されます

要らなくなったら **スクリプトを外す** を押します。編集は Ctrl+Z で戻せます。

## 動かす

1. ツールレールの **PLC** で「PLC連携」パネルを開く
2. モードを **部品スクリプト** にする
3. **▶ 実行** を押す。設備が原点に戻り、すべての部品のスクリプトが同時に最初から動きます

ウィンドウには部品ごとの状態(実行中・終了・エラー)、内部信号、ログが出ます。**■ 停止** で止めます。

## 例

```rhai
// ワークが来たらシリンダを出して戻す
loop {
    wait_signal("ワーク有", true);
    move_joint("押し出し", 1);
    wait(0.5);
    move_joint("押し出し", 0);
    set("押し出し完了", true);
}
```

別の部品のスクリプトで `wait_signal("押し出し完了", true);` と書けば、合図を受けて次の動きを始められます。

## 使える関数

| 関数 | 内容 |
| --- | --- |
| `get("信号")` | 信号を読む(true / false) |
| `set("信号", true)` | 信号を書く |
| `joint("関節")` | 関節の今の値 |
| `move_joint("関節", 値)` | 関節を目標値へ動かし、着くまで待つ |
| `wait(秒)` | 秒数だけ待つ |
| `wait_signal("信号", true)` | 信号がその値になるまで待つ |
| `wait_signal("信号", true, 最大秒)` | 最大秒まで待つ。来たら true、時間切れなら false |
| `time()` | シミュレーションの時刻(秒) |
| `log("文字")` / `print("文字")` | ログに出す |

- **信号** は「PLC連携」の I/O 一覧の名前(`シリンダ1.出`、`シリンダ1.出端` など)か、センサーの名前です。それ以外の名前を `set` すると、スクリプトどうしで共有する内部信号になります。
- **関節** はタイミングチャートのアクチュエータ(ロボットの関節も)の名前です。シリンダは 0 が戻端、1 が出端です。可動範囲を決めた関節に範囲の外を指定するとエラーになります。

## エラーのとき

知らない信号名、入力やセンサーへの書き込み、可動範囲外などのエラーは、ログに部品名付きで出て、そのスクリプトだけが止まります。
`wait` を入れずに計算だけを 2 秒以上続けるスクリプトは、無限ループとみなして止めます。
