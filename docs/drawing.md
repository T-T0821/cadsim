# 2D 図面と部品表のしくみ

使い方は操作マニュアルの [図面と部品表を書き出す](src/drawing.md) を見てください。

## 層の分け方

| 層 | 場所 | 役割 |
| --- | --- | --- |
| ドメイン | `crates/plantwright_core/src/drawing/mod.rs` | 投影・かくれ線・シルエット・寸法・尺度・図枠と表題欄。出来上がりは実寸の線と文字の集まり `Sheet` |
| ユースケース | `crates/plantwright_core/src/drawing/collect.rs` | `Model` から図面の材料(部品の面の三角形と稜線、寸法を付けるまとまり)を集める |
| ユースケース | `crates/plantwright_core/src/bom/mod.rs` | `Model` から部品表 `Bom`(まとめた行と、構成の木)を作る |
| アダプター | `src/formats/drawing_out.rs` | `Sheet` → PDF(krilla)/ DXF |
| アダプター | `src/formats/bom_out.rs` | `Bom` → CSV / Excel(rust_xlsxwriter) |
| UI | `src/features/drawing/mod.rs` | 設定のダイアログ、保存先の選択、書き出しの呼び出し |

## 図面

### 投影

上面図は「右 +X・上 −Z」、正面図は「右 +X・上 +Y」の平行投影です。配置は第三角法(正面図の上に上面図)。

### 描く線

1. **稜線**: 部品の B-rep の稜線(テッセレーションした折れ線)。ただし、両側の面が滑らかにつながる稜線(円柱の側面の継ぎ目など)は描きません。稜線の真ん中の線分を共有する2つの三角形の法線のなす角が約 20° より小さければ「滑らか」とみなします。滑らかでも、その向きから見て片側が表・片側が裏を向く稜線は輪郭なので残します。
2. **シルエット**: 曲面の見かけの輪郭。面のメッシュの中で、表を向いた三角形と裏を向いた三角形の境の辺をつなぎます。

### かくれ線

線を短い区間に分け、区間の真ん中から見る人の方向へレイを飛ばして、ほかの面に当たるかを調べます(`TriMesh::ray_blocked`。干渉チェックと同じ BVH を使います)。
当たれば破線(かくれ線)、当たらなければ実線(外形線)。外形線と重なるかくれ線は消します。

### 寸法と尺度

- **全体寸法**: すべての設備の外接箱の幅・奥行(上面図)と幅・高さ(正面図)。
- **直列寸法**: 設備の外接箱の端の座標を並べて、隣どうしの間隔を書きます。全体の 0.5% より近い端はまとめます。
- **尺度**: 1:1, 1:2, 1:5, 1:10, 1:20, 1:25, 1:50 … から、図と寸法の余白が A3 横の図枠(表題欄を除く)に収まる最小のものを選びます。

### 書き出し

- **PDF**: krilla で A3 横(420 × 297 mm)のページに描きます。かくれ線は破線、文字は同梱の Noto Sans JP(サブセット)を埋め込みます。
- **DXF**: AutoCAD R12 形式。実寸(尺度をかけない)で、線種 `HIDDEN` と画層 `OUTLINE`(外形線)・`HIDDEN`(かくれ線)・`DIM`(寸法)・`TEXT`(文字)・`FRAME`(図枠)を定義します。日本語は `\U+XXXX` で書きます。`$INSUNITS` にモデルの単位を入れます。

## 部品表

- **まとめ方**: 部品を「種類(箱 / 取り込み)・取り込み元のファイル・製品名・寸法」が同じものごとにまとめて数えます。寸法は 0.001 単位で丸めてから比べます。寸法は部品の座標系の外接箱です。
- **使用箇所**: その部品が入っている親アセンブリの名前を並べます。
- **CSV**: UTF-8(BOM 付き)、改行は CRLF。Excel でダブルクリックして開いても文字化けしないようにしています。
- **Excel**: 「部品表」と「構成」の2シート。構成はアセンブリの木を深さ優先で並べ、深さの分だけ全角スペースで字下げし、部品表の行番号とワールドの位置を付けます。
