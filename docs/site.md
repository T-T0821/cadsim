# 平面図の下敷きと点群のしくみ

使い方は操作マニュアルの [平面図を床に敷く](src/floor-plan.md)・[点群を読み込む](src/point-cloud.md) を見てください。

## 層の分け方

| 層 | 場所 | 役割 |
| --- | --- | --- |
| ドメイン | `crates/cadsim_core/src/site/underlay.rs` | 下敷きの配置(縮尺・原点・回転・高さ)、図面座標 ⇔ ワールド座標、縮尺合わせの計算 |
| ドメイン | `crates/cadsim_core/src/site/pointcloud.rs` | 点群の間引き・区画分け・LOD の段の選び方・部品との干渉と距離 |
| ドメイン | `crates/cadsim_core/src/site/model.rs` | プロジェクトに属する現場データ `Site`(`Model::site` に入る) |
| アダプター | `src/formats/dxf.rs` / `pdf_plan.rs` / `mod.rs` | DXF・PDF・画像 → `PlanContent`(折れ線と画像) |
| アダプター | `src/formats/pointcloud_read.rs` | PLY・LAS・E57 → 間引いた `PointCloud` |
| アダプター | `src/formats/site_record.rs` | `.cadsim` に書く記録(パスと配置と読み込みの設定)と、開くときの読み直し |
| UI | `src/site/` | 別スレッドの読み込み、3D 表示、縮尺合わせのクリック、「平面図・点群」パネル、干渉チェックの実行 |

`Site` は `Model` のフィールドにしているので、元に戻す履歴の「プロジェクトをまるごと写す」操作や、未保存の判定がそのまま効きます。

## 平面図

### 座標

図面の座標 (u, v) は「右が +u、上が +v」。cadsim は Y が上で、上面図は「右が +X、上が −Z」なので、
図面の点はワールドの `(origin.x + u', elevation, origin.z − v')` に置きます(`u', v'` は縮尺をかけて回したもの。`Underlay::to_world`)。

### 読み込み

- **DXF**: ENTITIES と BLOCKS を読み、線として見えるものを折れ線にします。LWPOLYLINE のふくらみ(bulge)は円弧に、CIRCLE / ARC / ELLIPSE / SPLINE は折れ線に分けます。INSERT はブロックの中身を位置・尺度・回転を付けて展開します(入れ子も)。`$INSUNITS` があれば単位(mm など)が分かるので、実寸で敷けます。
- **PDF**: 1ページ目の描画命令をたどり、`m` / `l` / `c` / `re` などのパスを折れ線にします。`cm` と `q` / `Q` の座標変換、フォーム XObject の入れ子に対応します。画像はいちばん大きいもの(JPEG か 8bit の RGB / グレー)を下敷きの画像にします。単位はポイント(1/72 インチ)。
- **画像**: `image` crate で RGBA にします。単位がないので、幅が 10 m になる縮尺で仮に敷きます。

### 表示

折れ線は LineList のメッシュ1つにまとめ、画像はテクスチャを貼った四角形にします(GPU の上限を超えないよう、長い辺を 8192 px までに縮める)。
ピック(部品の選択)の対象にはしないので、上に置いた設備のクリックをじゃましません。

### 縮尺合わせ

1. クリックした画面の点から床(高さ = 下敷きの高さ)へのレイを飛ばして交点を求め、図面座標に戻します。図面の頂点が画面上で 12 px 以内にあれば吸い付きます(`Underlay::nearest_vertex`)。
2. `Underlay::calibrate(a, b, distance)` で、2点の図面上の長さが `distance` になるよう縮尺を変えます。1点目のワールド位置は変えません。
3. 必要なら `align_to_x`(1点目 → 2点目を +X に向ける回転)と `place`(1点目を原点に)をかけます。

縮尺合わせ中は `PlanTool` が有効になり、部品のクリック選択(`viewport::pick_part`)を止めます。

## 点群

### 間引き(`Decimator`)

読み込みながら1点ずつ渡し、「ボクセル(一辺 `voxel` の立方体)1つに1点」だけ残します。残った点が上限(`budget`、既定 300 万)を超えたら、ボクセルを2倍にして間引き直します。
メモリは上限の点数ぶんしか使わないので、数億点のファイルでも読めます。

座標は読み込んだ点の真ん中を原点にした f32 で持ちます。測量座標のような大きな値でも精度が落ちません。

### LOD

間引いた点を決まった種でばらばらに並べ替えておくと、先頭から何点取っても全体から均等に選んだことになります。
床を区画(タイル、1区画あたり約 6 万点)に分け、カメラからの距離に応じて区画ごとに 1、1/4、1/16、1/64 の4段から描く点の割合を選びます(`lod_level`)。
段ごとのメッシュは「先頭の N 点」なので、作り直さずに区画ごとに切り替えるだけです。

### 干渉と距離(`check_body`)

点群は格子の索引(`grid`)で引けるようにしておき、部品の外接箱(警告距離ぶん広げたもの)に入る点だけを調べます。

- 部品のメッシュの内側にある点 → 干渉。数と、表示用に最大 2000 点を返します。
- 外側の点 → 部品の表面までの距離を `TriMesh::closest_point` で求め、警告距離より近いもののうち最小を返します。

調べる点が多いとき(1部品あたり 40 万点超)は間を飛ばして調べ、数はその分を掛けて見積もります。
判定は `AsyncComputeTaskPool` で裏で行い、部品の配置か点群が変わったときだけやり直します(自動のとき)。

### 形式ごとの読み込み

| 形式 | 実装 |
| --- | --- |
| PLY | ヘッダーを読み、ASCII / binary_little_endian / binary_big_endian の vertex 要素から x, y, z と red, green, blue を取ります |
| LAS | 1.0〜1.4、点の形式 0〜10。スケールとオフセットをかけ、色のある形式なら 16bit の色を 8bit にします。LAZ(圧縮)は読めません |
| E57 | `e57` crate。スキャンごとの姿勢を反映した直交座標と色を取ります |

LAS / E57 は m・Z 上、PLY は「OBJ / STL の単位」の設定に従います。Z 上のデータは読み込むときに Y 上に直します。
