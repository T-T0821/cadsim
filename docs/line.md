# ライン連携のしくみ

工程シミュレーション・AGV・作業者・タイミングチャート・安全機器を、1つの時計で一緒に動かすしくみです。
使い方は README の「工程・AGV・安全機器をつないでラインとして動かす」を見てください。

## 置き場所

| 層 | 場所 | 中身 |
| --- | --- | --- |
| ドメイン | `cadsim_core::flow::sim` | ライン連携の口: `Simulation::link`・`take_events`・`pick_up`・`deliver`・`set_source_enabled` |
| ドメイン | `cadsim_core::line::coupler` | 工程の出来事と AGV の出来事の受け渡し (`LineCoupler`) |
| ドメイン | `cadsim_core::line::signals` | PLC とやりとりする信号表と、PLC → 設備の値 (`LineInputs`) |
| ドメイン | `cadsim_core::line::workpieces` | 3D に描くワークの位置 (積む・渡る・置き場所の決め方) |
| アプリ (Bevy 非依存) | `src/line/stepper.rs` | 工程と AGV を同じ時間だけ少しずつ進める。AGV のシミュレーションがアプリ側にあるのでここに置く |
| UI | `src/line/mod.rs`・`view.rs`・`panel.rs` | 毎フレームの進め方、3D のワーク、「ライン連携」ウィンドウ |

## 1つの時計

ライン連携の再生中は、毎フレーム `実時間の経過 × 倍速` 秒だけ、次の順に進めます。

1. 止める条件を見る。安全停止中 (`SafetyState::is_stopped`) か、PLC の「ライン.運転」が OFF なら何も進めない。
2. 工程シミュレーションと AGV を、最大 0.25 秒ずつ交互に進める (`stepper::step`)。1 歩ごとに出来事を受け渡す。
3. 作業者の時計 (`FloorClock::time`) を同じだけ進める。作業者と AGV は安全機器の検知の対象なので、このあと同じフレームで検知が走る。
4. タイミングチャートの再生 (`Playback`) を、ラインと同じ倍速で流す。「チャート起動」の工程があれば、その工程が加工を始めたときだけ頭から再生する。

工程シミュレーションと「作業者・AGV」パネルのそれぞれの再生フラグは、連携中は毎フレーム下ろしておき、二重に進まないようにしています。
工程モデル・AGV の経路が途中で変わったら、それまでの状態に意味がなくなるので止めて、次の再生で最初から回します。

## 工程と AGV の受け渡し

工程モデルの要素に `carrier: Some(AgvCall { from, to })` を付けると、その要素は送り出せるワークができても自分では下流へ動かしません。

```text
工程シミュレーション            LineCoupler                 AgvSim
  ワークができた ── CarrierNeeded ──▶ 荷札 tag を振る ── request(from, to, tag) ──▶ 配車
                                                                         積み込み完了
  pick_up(要素) ◀──────────────── PickedUp{tag} ◀──────────────────────────┘
  (空いた所に上流から次が入る)                                            荷降ろし完了
  deliver(荷) ◀─────────────────── Delivered{tag} ◀─────────────────────────┘
  (送り先が空いていなければ空くまで待つ)
```

- 積まれている間のワークは工程シミュレーションの「運搬中」に入り、仕掛数に数えます。
- 降ろし先へ行けずに AGV が搬送をあきらめたとき (`Abandoned`) は、ワークがなくならないように、その場で送り先へ入れます。
- AGV のシミュレーションがないときは、頼んだ搬送はすぐ届いたことにします。
- 工程シミュレーションのウィンドウだけで回すとき (`Simulation::run` や連携していない `advance`) は `carrier` を見ません。いままでどおりすぐ下流へ送ります。

## 信号表

信号は工程モデルの要素の名前から毎回作ります。保存はしません。番号はタイミングチャートのアクチュエータの信号 (0 番台・100 番台) と重ならないよう、次の先頭から表の順に詰めて振ります。

| 領域 | 先頭 | 中身 |
| --- | --- | --- |
| 設備 → PLC のビット | 200 | `ライン.運転中`・`安全.停止`、工程ごとの `稼働`・`詰まり`・`故障`・`在荷`、バッファの `満杯`、`AGV<n>.搬送中` |
| 設備 → PLC のワード | 200 | `ライン.排出数`、バッファの `数`、`AGV.搬送待ち` |
| PLC → 設備のビット | 300 | `ライン.運転`、生成ごとの `投入許可` |

PLC → 設備の値は `LineInputs` に持ち、名前で書けます (`LineInputs::set`)。名前が表にない信号は ON とみなすので、PLC をつながなくてもラインは動きます。

PLC 連携 (docs/plc.md) とは `src/line/mod.rs` の `exchange_plc` でつなぐ。毎フレーム信号表を PLC 連携の I/O に書き (`Plc::exchange_line`)、外部 PLC かログ再生が PLC → 設備の信号を書いているときは、その値を `LineInputs` に写す。そのあいだは画面での切り替えはできない。
投入許可が OFF の間は、生成は次のワークを出しません。出す時刻を過ぎてから ON に戻ると、すぐに 1 個出します。

## 3D のワーク

- 置き場所は、3D の部品を対応付けた要素はその部品の上面の中心、ないときは AGV で送り出す要素なら積み込みのステーション、AGV で届く先の要素なら荷降ろしのステーションの台 (高さ 700 mm) の上です。どちらもない要素は描きません。
- 設備の中のワークは 3×3 の格子に積み、あふれたら上の段へ。
- AGV を使わずに設備から設備へ移ったワークは、1.5 秒 (ラインの時間) かけて弧を描いて移ります。その間は届く先の山には数えません。
- AGV に積まれているワークは、AGV の上に描きます。

どれもギズモの立方体で描き、メッシュは作りません。

## これから

- 作業者のボタン操作 (`OperatorTask::Button`) を PLC の入力にする。
