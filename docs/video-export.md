# 動画書き出しのしくみ

タイミングチャートの再生を、MP4 (H.264) / GIF / PNG 連番に書き出します。外部ツール (ffmpeg など) は使いません。

## コマの撮り方

実時間で再生しながら録画するのではなく、1 コマずつ時刻を決めて撮ります。

1. `n` 枚目のシミュレーション時刻を `n × 再生速度 ÷ fps`(サイクル時間で割った余り)にする。
2. その時刻に再生位置 (`Playback.time`) を合わせ、同じフレームで `Screenshot::primary_window()` を出す。
   再生位置は `MotionSet::Pose` より前に決めるので、部品の位置・稜線・タイミングチャートの再生線がそろった絵が撮れる。
3. キャプチャが届くまで次の時刻へ進まない。届いたら切り抜いてエンコーダへ渡す。

描画の速さに関係なく撮る時刻がフレーム番号だけで決まるので、PC が遅くてもコマ落ちせず、毎回同じ動画になります。
最後のコマはサイクルの終わりの手前までにしてあり、繰り返し再生しても同じ絵が 2 枚続きません。

書き出し中は次のものを止めます。

- 3D ビューのマウス操作とキーボードショートカット(`camera::pointer_in_3d_view` / `keyboard_free` が false を返す)
- タイミングチャートの編集の反映(表示だけ行う)
- ウィンドウタイトルの更新(進み具合を出すため)

設定ウィンドウは動画に映らないよう隠します。終わると再生状態とタイトルを元に戻します。

## カメラワーク (カメラの通り道)

紹介動画用に、動画の秒数ごとにカメラの視点を置いた通り道 (`plantwright_core::camera_path::CameraPath`) を持てます。
視点は 3D ビューのカメラ (`OrbitCamera`) と同じ「注視点・ヨー・ピッチ・距離」で表します。

- つなぎ方は 2 通り。**なめらか** は 3 次エルミート補間で、途中の視点の速さは前後の視点から決め (Catmull-Rom と同じ考え方を時刻の間隔が不ぞろいでも使えるようにしたもの)、最初と最後の視点では速さ 0 にしてゆっくり動き出して止まる。**一定の速さ** は区間ごとの線形補間。
- 距離は対数でつなぐ。遠くから寄るときに、近づくほどゆっくりになる自然な動きになり、距離が負にもならない。
- ヨーは前の視点から近い向きへ回るようにつなぐ (359° → 1° で一周しない)。「ぐるっと一周」は 90° ずつ視点を置くので一周できる。
- 書き出すときは `FramePlan::extend_to` で通り道の終わりまでコマを足し、`n` 枚目は動画の `n ÷ fps` 秒目の視点にカメラを合わせてから撮る。チャートの時刻はいつもどおりサイクルでくり返す。カメラの視点も再生位置と同じく `CameraSystems` (カメラの反映) より前に決める。撮り終えたら元の視点に戻す。
- プレビューは実時間で通り道をたどり、チャートの再生位置も書き出しの再生速度に合わせて動かす。
- `.plantwright` には `camera_path` として、秒数・注視点・ヨー / ピッチ (度)・距離を書く (`plantwright_core::camera_path::record`)。元に戻す履歴には `TrackedDoc` で載せる。

## コードの置き場所

| モジュール | 層 | 内容 |
| --- | --- | --- |
| `plantwright_core::video` | ドメイン + ユースケース | `FramePlan`(何枚・どの時刻)、`Frame`(切り抜き・縮小)、`RecordingSession`、書き込み先のポート `VideoSink` |
| `video::encode` | アダプター | `VideoSink` を実装する `EncoderThread`。別スレッドで MP4 / GIF / PNG に書く |
| `video::mp4` | アダプター | H.264 を MP4 に入れる最小限のライター |
| `plantwright_core::camera_path` | ドメイン | カメラの通り道 `CameraPath`(視点の足し方・並べ直し・補間・「ぐるっと一周」などの作り方) |
| `plantwright_core::camera_path::record` | アダプター | `.plantwright` に書くカメラワークの形 |
| `recording` | UI | 設定ウィンドウ、保存ダイアログ、Bevy のスクリーンショット、Esc での中止、書き出し中のカメラの視点 |
| `view::camera_path` | UI | カメラワークの欄、3D ビューの通り道の線、プレビュー、元に戻す履歴への登録 |

`plantwright_core::video` と `src/features/video/` は Bevy に依存せず、`cargo test` で単体テストできます。

## 形式ごとの書き方

- **MP4**: RGBA を BT.601 の YUV 4:2:0 に変換し、OpenH264(`openh264` crate が同梱の C++ ソースをビルド)で H.264 にする。
  出てきた Annex-B の NAL から SPS / PPS を `avcC` に入れ、残りを長さ前置き形式で `mdat` に書く。`moov` は最後に書く。
  4:2:0 は偶数サイズが必要なので、右端・下端の 1 ピクセルを切ることがある。キーフレームは 2 秒ごと。
- **GIF**: コマごとに NeuQuant で 256 色に減色する。待ち時間は 1/100 秒単位なので、端数を次のコマに回して全体の長さを合わせる。
- **PNG 連番**: 選んだ名前のフォルダに `frame_00000.png` から順に書く。
