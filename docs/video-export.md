# 動画書き出しのしくみ

タイミングチャートの再生を、MP4 (H.264) / GIF / PNG 連番に書き出します。外部ツール (ffmpeg など) は使いません。

## コマの撮り方

実時間で再生しながら録画するのではなく、1 コマずつ時刻を決めて撮ります。

1. `n` 枚目のシミュレーション時刻を `n × 再生速度 ÷ fps`(サイクル時間で割った余り)にする。
2. その時刻に再生位置 (`Playback.time`) を合わせ、同じフレームで `Screenshot::primary_window()` を出す。
   再生位置は `MotionSet::Pose` より前に決めるので、部品の位置・稜線・タイミングチャートの再生線がそろった絵が撮れる。
3. キャプチャが届くまで次の時刻へ進まない。届いたら切り抜いてエンコーダへ渡す。

描画の速さに関係なく撮る時刻がフレーム番号だけで決まるので、PC が遅くてもコマ落ちせず、毎回同じ動画になります。
最後のコマはサイクルの終わりの手前までにしてあり、繰り返し再生しても同じ絵が 2 枚続きません。

書き出し中は次のものを止めます。

- 3D ビューのマウス操作とキーボードショートカット(`camera::pointer_in_3d_view` / `keyboard_free` が false を返す)
- タイミングチャートの編集の反映(表示だけ行う)
- ウィンドウタイトルの更新(進み具合を出すため)

設定ウィンドウは動画に映らないよう隠します。終わると再生状態とタイトルを元に戻します。

## コードの置き場所

| モジュール | 層 | 内容 |
| --- | --- | --- |
| `cadsim_core::video` | ドメイン + ユースケース | `FramePlan`(何枚・どの時刻)、`Frame`(切り抜き・縮小)、`RecordingSession`、書き込み先のポート `VideoSink` |
| `video::encode` | アダプター | `VideoSink` を実装する `EncoderThread`。別スレッドで MP4 / GIF / PNG に書く |
| `video::mp4` | アダプター | H.264 を MP4 に入れる最小限のライター |
| `recording` | UI | 設定ウィンドウ、保存ダイアログ、Bevy のスクリーンショット、Esc での中止 |

`cadsim_core::video` と `src/video/` は Bevy に依存せず、`cargo test` で単体テストできます。

## 形式ごとの書き方

- **MP4**: RGBA を BT.601 の YUV 4:2:0 に変換し、OpenH264(`openh264` crate が同梱の C++ ソースをビルド)で H.264 にする。
  出てきた Annex-B の NAL から SPS / PPS を `avcC` に入れ、残りを長さ前置き形式で `mdat` に書く。`moov` は最後に書く。
  4:2:0 は偶数サイズが必要なので、右端・下端の 1 ピクセルを切ることがある。キーフレームは 2 秒ごと。
- **GIF**: コマごとに NeuQuant で 256 色に減色する。待ち時間は 1/100 秒単位なので、端数を次のコマに回して全体の長さを合わせる。
- **PNG 連番**: 選んだ名前のフォルダに `frame_00000.png` から順に書く。
