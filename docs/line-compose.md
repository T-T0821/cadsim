# 言葉でラインを組む

「コンベア2本とロボット1台で箱詰め」のような文から、設備の配置とタイミングチャートの下書きを作る機能の設計です。

## 流れ

```text
文 ──▶ usecase::compose_line ──▶ ComposedLine (下書き + 並べ方 + 警告) ──▶ line_compose::apply ──▶ Model / TimingChart / ConveyorConfig
          │
          ├─ LineDraftAi (ポート) があれば生成 AI に下書きを作らせる
          └─ なければ・失敗したら line_draft::rules (キーワード) で作る
          ↓
       line_draft::check::normalize で整え、line_draft::layout で並べる
```

| 層 | 場所 | 中身 |
| --- | --- | --- |
| ドメイン | `cadsim_core::line_draft::{model, check, layout, rules}` | 下書きの型、整え方、床への並べ方、キーワードからの下書き |
| ユースケース | `cadsim_core::usecase::compose_line` | 生成 AI のポート `LineDraftAi` と、AI → キーワードの順で試す `compose_line` |
| UI | `src/line_compose/` | ウィンドウ (`mod.rs`)、モデルとチャートへの反映 (`apply.rs`、Bevy 非依存)、AI の口の用意 (`ai.rs`) |

## 下書きの型

- `LineDraft`: 名前、設備 (`Equipment`) の一覧、ステップ (`DraftStep`) の並び、メモ。
- 設備の種類 (`EquipmentKind`): コンベア・ロボット・シリンダ・センサー・作業台。位置 `[x, z]` (mm) とコンベアの長さは省略でき、省略したものは `layout` が決める。
- ステップ: 同時に始まる動作 (`DraftAction`) の並び、開始条件 (センサーの ON / OFF 待ち)、動作後の待ち時間。
- 動作 (`Verb`): コンベアの搬送 (run)、シリンダの出 / 戻 (extend / retract)、ロボットの取る / 置く (pick / place、場所はコンベアか作業台)。

## 整え方 (`check::normalize`)

生成 AI の出力は崩れていることがあるので、配置の前に次を直し、直したところを警告にする。

- 名前が空なら「種類 + 番号」、重なったら `-2` などを足す。
- ない設備への動作、種類に合わない動作 (ロボットに run など) は外す。
- 取る・置く場所がない・コンベアでも作業台でもないときは、取るのは最初の、置くのは最後のコンベア / 作業台にする。
- 秒数は 0.1〜120 秒、コンベアの長さは 300〜20000 mm に収める。1つのステップで同じ設備に2つ動作があれば1つ目だけ残す。
- センサーでない開始条件は外す。何もしないステップは外す。設備が1つもなければエラー。

## 並べ方 (`layout`)

単位は mm、Y が上、コンベアは +X に流れる。

- コンベアは X 向きに、Z 方向へ 1600 mm 間隔で平行に並べる。
- ロボットはコンベアの間 (1本ならその手前) の下流の端の近く。複数のときは間を順に使い、埋まったら上流へずらす。
- 作業台は、コンベアが2本以上ならロボットの下流側、そうでなければロボットの向こう側。
- センサーとシリンダは、それぞれ1本目のコンベアから順に割り当て、下流の端の +Z 側 (センサー) と -Z 側 (シリンダ) に付ける。

## キーワードからの下書き (`rules`)

- 台数: 「コンベア2本」「ロボット 1台」「2台のロボット」「センサー×3」「コンベヤー三本」を読む (半角・全角・漢数字)。数がなければ1台。1種類8台まで。
- 作業: 箱詰め・検査・組立。どれもなければ移載。
- ステップ: 1本目のコンベアで送る → シリンダで位置決め (センサー ON 待ち) → 検査 / 組付けの待ち → ロボットで取る・置く (置くときに位置決めを戻す) → 最後のコンベアで送り出す。
- ロボットがあるのに取る・置く場所が2つないときは「置き台」を足す。

## モデルとチャートへの反映 (`apply`)

設備は標準部品ライブラリ ([library.md](library.md)) の部品で作り、標準部品のないもの (ロボットの土台と腕、作業台) は箱で作る。すべてアセンブリ「ライン下書き: …」にまとめる (Ctrl+Z 1回で消せる)。既存のモデルがあれば、その右 (+X) に 1 m あけて置く。寸法は mm で考え、モデルの単位 (cm・m など) に直して置く。

| 設備 | 部品 | チャート |
| --- | --- | --- |
| コンベア | 標準部品のベルトコンベア (機長・ベルト幅・搬送面の高さを合わせる) | なし (ワーク搬送のコンベアとして登録)。搬送は待ち時間として入る |
| ロボット | 土台・腕の箱、ハンドは上下逆さに吊るした標準部品のエアチャック | 回転テーブル「旋回」(腕とハンド)、その上のシリンダ「上下」(ハンド)。取る・置くは「旋回 → 下降 → 上昇」の3ステップ (時間の 4:3:3) に展開。旋回角は場所への向き、腕の長さは届く長さにする |
| シリンダ | 標準部品のエアシリンダ (ストローク 150 mm)。コンベアへ向け、ロッドの先がコンベアの縁に来るよう置く | ロッドとロッド先端の本体を Z 向きに 150 mm 動かすシリンダ |
| センサー | 柱の箱と、その上の標準部品の光電センサー (光軸は搬送面の 50 mm 上) | コンベアを横切る光電センサー。ワークを流さなくても再生が止まらないよう強制 ON |
| 作業台 | 箱 | なし |

ステップは今あるチャートのステップの後ろに足す。サイクルの終わりに旋回したまま・出たままのアクチュエータがあれば、最後に「原点へ戻る」ステップを足す。動く部品と土台・本体のあいだは 2 mm あけ、干渉チェックで「接触」と出ないようにする。

## 生成 AI

- ポート `LineDraftAi` は、文から `LineDraft` を返すだけ。実装は `cadsim_io::line_draft_json::LlmLineDrafter` で、共通の `LlmClient` ([ai.md](ai.md)) に問い合わせる。
- 指示は `SYSTEM_PROMPT`、返事の形は構造化出力の `SCHEMA` で決める。構造化出力ではすべての項目を必須にするので、「なし」は空文字 (target・wait_sensor) と 0 (length) で表し、`parse` で None に戻す。位置は AI に決めさせず `layout` で並べる。
- 画面は「AI の設定」の API キーがあるときだけ AI を使う。問い合わせは `LlmJob` で別スレッドに投げる。AI が失敗したとき (キーの誤り・通信・返事の形) は、理由を警告に出してキーワードから作り直す。
- テストは `ScriptedLlm` で決まった返事を返して書く (送った指示と Schema、返事の読み取り)。
