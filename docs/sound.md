# 設備の音と警報

再生中の設備の稼働音・エアの排気音と、停止・干渉の警報を鳴らすしくみです。

## 層の分け方

| 層 | 場所 | 中身 |
| --- | --- | --- |
| ドメイン | `cadsim_core::sound` | 波形の合成 (`synth`)、音量 (`settings`)、聞こえ方 (`spatial`)、鳴らす音の決め方と動きの見張り (`cues`)、警報とブザー停止 (`alarm`) |
| アダプター | `cadsim_io::sound_settings` | 設定ファイル `sound.json` の読み書き |
| UI | `src/sound/` | `mod.rs` が毎フレーム状態を集めて `plan_sounds` を呼び、音を出し入れする。`source.rs` が波形を Bevy の音にする。`panel.rs` が設定ウィンドウと警報の帯 |

判断はすべて `cadsim_core::sound` にあり、Bevy なしで単体テストできます。

## 音の波形

録音した音のファイルは使わず、起動後に初めて鳴らすときに正弦波と雑音から作ります (`synthesize`)。使用許諾の心配がなく、実行ファイルも大きくなりません。44.1 kHz・モノラルで、種類ごとに 1 回だけ作って使い回します。

| 種類 | 作り方 | 鳴らし方 |
| --- | --- | --- |
| モーター (`MotorHum`) | 100 Hz とその倍音 + ならした雑音 | くり返し |
| サーボ (`ServoWhine`) | 120 Hz のうなり + 8 Hz でゆれる 1.8 kHz | くり返し |
| コンベア (`ConveyorRumble`) | 低域だけ残した雑音 + 50 Hz + 6 Hz のローラー音 | くり返し |
| エアの排気 (`AirExhaust`) | 高域だけ残した雑音を 5 ms で立ち上げ、指数で減らす | 1 回 |
| 警報 (`Alarm`) | 880 Hz と 660 Hz を 0.5 秒ずつ (奇数倍音を足す) | くり返し |
| 干渉 (`WarningBeep`) | 1.32 kHz を 0.12 秒ずつ 2 回 | 1 回 |

くり返す音は、周波数を整数 Hz にして長さの中でちょうど元に戻るようにし、雑音は少し長く作ってはみ出した分を先頭に重ねて継ぎ目を消します。どの音も最大値を 0.8 にそろえます。

## 鳴らす条件

`plan_sounds` が 1 フレーム分の状態 (`MachineFrame`) から、鳴らし続ける音 (`Voice`) と 1 回だけ鳴らす音 (`OneShot`) を決めます。

- **動いているか** はアクチュエータの値 (`SimulationPose::values`) の変化で見ます (`MotionTracker`)。チャートの再生・PLC 連携・ライン連携・スクラブのどれでも同じように鳴ります。値が変わってから 0.12 秒は動いているとみなし、描画が速くて同じ値のフレームが挟まっても途切れないようにしています。初めて見たアクチュエータ (プロジェクトを開いた直後など) は動き始めとみなしません。
- 直動軸はサーボ、回転テーブル (URDF のロボットの関節も回転テーブル) はモーターの音を、動いている間鳴らします。シリンダは動き始めに排気音を 1 回鳴らします。
- コンベアは、チャートかライン連携を再生している間 (`Playback::playing` か `LineState::is_running`) 鳴らします。
- 鳴らし続ける音は、聞こえる大きさの順に 8 つまでにします (`MAX_VOICES`)。警報はこの数に入れず、いつも鳴らします。
- 干渉の「ピピッ」は、設備が動いている間に干渉している組が増えたときだけ鳴らします (`InterferenceWatch`)。止まっている間に部品を置き直して干渉しても鳴りません。

## 警報とブザー停止

警報の理由 (`AlarmReason`) は次の 2 つです。

- **安全停止**: `SafetyState::is_stopped`
- **インターロック停止**: 時刻表に止まった時刻 (`Schedule::stop`) があり、再生がそこまで来て止まっている (`interlock_stopped`)

`AlarmLatch` が理由の集まりと確認済みの理由を持ちます。確認していない理由があれば警報を鳴らします。「ブザー停止」は今ある理由を確認済みにし、別の理由が加わったときか、一度直ってからまた起きたときに鳴らし直します。警報の帯は理由が残っている間ずっと出し、鳴っている間は赤を点滅させます。

## 聞こえ方

カメラの位置で聞きます (`spatial::place`)。歩行モードでは歩いている人の目の位置です。音の位置は、アクチュエータが動かす部品の設計位置での外接箱の中心を、その時刻のアクチュエータの動きで動かした点です (コンベアはベルトの部品の中心)。

- 大きさ: 注視点までの距離 (`OrbitCamera::distance`、歩行モードでは 3 m) を基準にし、それより近ければそのまま、遠ければ `基準 / 距離` にします (下限 0.08)。拡大して見ている設備の音が大きくなり、どの倍率で見ても全体の音量は大きく変わりません。
- 左右: 音の向きと画面の右の向きの内積から決め、±0.8 までにします。左右の倍率は等パワー (真ん中で両方 1/√2)。

Bevy の空間音声 (距離の 2 乗で小さくなる) は CAD の縮尺に合わないので使わず、音ごとの [`SynthSound`] アセットが左右の倍率を原子変数で持ち、音を鳴らすスレッドが毎サンプル読みます。急に変わってもプツッと鳴らないよう、約 30 ms かけて近づけます。鳴らさなくなった音は 0.15 秒かけて小さくしてから消します。

最終的な大きさは `距離による大きさ × 種類ごとの基本の大きさ × 全体の音量 × 種類ごとの音量` です。ミュート中は何も鳴らしません。

## 設定ファイル

`preferences.json` と同じフォルダ (環境変数 `CADSIM_CONFIG_DIR` で差し替え可) の `sound.json` に、ミュートと 4 つの音量 (0〜1) を書きます。

```json
{
  "muted": false,
  "master": 0.7,
  "machine": 0.8,
  "air": 0.8,
  "alarm": 1.0
}
```

足りない項目は標準の値で埋め、範囲外の値は 0〜1 に収めます。壊れたファイルは無視して標準の設定で始めます。音を出す装置がない PC (画面の自動確認を流す CI など) では、Bevy が警告を 1 回出して音を鳴らさずに動きます。
