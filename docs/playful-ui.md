# ゲーム風の画面(配色・ツールレール・AI に聞く・ミッション・経験値)

ツールに慣れていない人の心理的なハードルを下げるため、画面をゲームのように「次にやること」「できたらほめる」形にしています。
見た目はゲーム風の1種類だけです(以前あった「シンプル」のテーマはなくしました)。
ミッションカードは「隠す」か「表示 → ミッションカードを表示」で消せるので、演出が邪魔なときはそちらを使います。

## 画面の組み立て

- 3D ビューの上に浮かぶ道具のパネル(干渉チェック・寸法・安全・PLC 連携など)は、はじめはすべて閉じておき、左端の **ツールレール** とメニューの「ツール」から開け閉めする。
  以前は 10 枚近いパネルが四隅に固定で浮いていて、ビューを覆い・重なっていた。
- 道具の一覧(名前・短い名前・説明・分類・並び順)と「どれを開いているか」は `plantwright_core::workspace` にある。
  `Workspace` は開いた順を覚え、小さなパネルを最初に出す位置を開いた順に 28 px ずつ右下へずらす(6 枚で一周)。大きな作業用のウィンドウ(工程シミュレーションなど)はずらす数に入れない。
- UI 層の `src/ui/dock.rs` はそれを `Dock` という Resource に包み、レールのボタンと、パネルの枠 (`dock::panel` / `dock::workspace_window`) を作る。各機能のパネルのシステムは `Dock` を見て、閉じていれば何も描かない。パネルの × で閉じたら `Dock` に書き戻す。
- レールのボタンには印を付けられる(`Badge`)。干渉している組の数と、安全停止中の印を出して、パネルを閉じていても気づけるようにしている。
- 道具を足すときは、`Tool` と `Tool::ALL` に足し、`title` / `short_label`(全角 4 文字まで)/ `hint` / `group` を書き、`dock::icon` にアイコンを足す。パネルのシステムでは `dock::panel(Tool::…, &dock, viewport.rect)` で枠を受け取る。

## AI に聞く

ツールバー右端の「💬 AI に聞く」(F1)で、使い方を会話で質問できる。

| 層 | 場所 | 役目 |
| --- | --- | --- |
| ユースケース | `crates/plantwright_core/src/assistant/help.rs` | システムプロンプト(画面の配置、道具の一覧、キー操作 `SHORTCUTS`、いまの画面の様子 `HelpContext`)を組み立て、`LlmClient` に問い合わせる。返事の `[[open:道具の名前]]` を `parse_answer` で道具に変える。キーがないときの `suggest_tools`(質問の言葉と道具ごとの言葉を照らし合わせる) |
| UI | `src/features/assistant/help.rs` | `HelpChat`(会話・入力欄・問い合わせ中のジョブ)と「AI に聞く」ウィンドウ。答えの道具は「○○ を開く」ボタンにして `Dock` を開く |

- 道具の一覧とキー操作の一覧はアプリのデータから作るので、道具を足せば AI への説明にも自動で入る。
- 会話は `LlmMessage` の列として毎回送る(問い合わせは `Effort::Low`、返事は 2000 トークンまで)。
- ほかの画面からは `HelpChat::ask(質問文)` で、質問欄に文面を入れた状態で開ける(送るのはユーザーが押してから)。

## 配色と文字

`src/ui/theme.rs` の `palette` に色を集めている。紺(`INK` → `NAVY_DEEP` → `NAVY` → `NAVY_LIGHT` の順に明るい)を土台に、選択と押したボタンは紫(`PURPLE`)、カーソルを乗せた枠と「開いている」印は水色(`TEAL`)、経験値やレベルは黄・橙。
日本語は欧文より字面が小さく見えるので、本文とボタンは 13.5 px、見出しは 17 px にしている。

## ミッションの層の分け方

| 層 | 場所 | 役目 |
| --- | --- | --- |
| ドメイン | `crates/plantwright_core/src/gamify.rs` | ミッションの一覧、達成の判定、経験値とレベル、紙吹雪の軌道。Bevy・egui なしで単体テスト |
| アダプター | `crates/plantwright_core/src/preferences.rs` | 設定 (`Preferences`) と JSON の変換、OS ごとの設定フォルダへの読み書き |
| UI | `src/ui/theme.rs` | egui の `Style` (配色・角丸・余白・文字の大きさ) と 3D ビューの背景色 |
| UI | `src/ui/playful.rs` | 画面の状態を集めて `Progress::observe` に渡し、カード・マスコット・お祝い・紙吹雪を描く |
| UI | `src/ui/tutorial.rs` | ようこそ画面、カードの中の手順・キー・「とばす」、操作する場所を指す矢印 |

## 最初の5分 (起動時のデモラインとようこそ画面)

- 引数なしで起動すると、`file_io::open_command_line_file` が `ProjectAction::OpenDemoLine { play: true }` を頼む。`project.rs` は埋め込みの `samples/demo_line.plantwright` (`include_str!`) を別スレッドで読み、ファイルに結びつけない無題のプロジェクトとして開いて、タイミングチャートを繰り返し再生にする。保存すると名前を聞かれる。
- `--bench` だけは前と比べられるよう、これまでどおりサンプルの STEP (`assets/sample_assembly.step`) で測る。
- 起動直後に読み込みが終わるまでは「保存済み」の状態に含めるので、デモラインを開いただけでは閉じるときに確認が出ない。
- 設定の `welcomed` が false のあいだ (初回) は `tutorial::draw` がようこそ画面を出し、ミッションカードは隠す。「チュートリアルを始める」「自由にさわる」「空のプロジェクトから」のどれかで閉じる。「ヘルプ → ようこそ画面」で `TutorialUi::welcome_requested` を立てると開き直せる。

## 章と手順

ミッションは `Chapter` にまとめ、章は `Part` の基本編 (見る → さわる → ラインを組む → 仕上げる) と応用編 (動きを付ける → ラインとして動かす → 使いこなす) に分ける。`MISSIONS` の並び順がそのまま進む順になる (章が前に戻らないこと、基本編の章が先に並ぶことをテストで確かめている)。
各 `Mission` は 1 行のヒント (`hint`) のほかに、チュートリアルの手順 (`steps`)、何の役に立つか (`why`)、使うキー (`keys`)、操作する場所 (`place`)、使う道具 (`tool`、`plantwright_core::workspace::Tool`)、設備が止まっている必要があるか (`needs_stopped_line`) を持つ。

- カードは今のミッションの章名、章の中の進み具合 (● 達成 / ◉ 今 / ◌ とばした / ○ まだ)、手順、キーの形を出す。「▲ 手順をたたむ」で 1 行のヒントだけにできる。
- `tool` があるミッションでは、その道具のパネルが閉じているときにカードへ「📦 部品ライブラリを開く」のようなボタンを出し、押すと `Dock::set_open` で開く。
- 「💬 AI に聞く」は `assistant::help::HelpChat::ask` に「ミッション「◯◯」のやり方がわかりません…」という文を渡して開くだけ。送信はユーザーが押す。
- `place` を見て、新しいミッションになってから 8 秒間 (または「👉 どこ?」を押したとき) 3D ビューの上に点滅する矢印や枠を描く。3D ビュー (`ViewportRect`) の端からの位置で決める。ツールレールは画面の左端 (`dock::RAIL_WIDTH`) を指す。
- ギズモでの編集は設計位置で止まっているときしかできない (`motion::at_design_pose`)。`needs_stopped_line` のミッションで再生中・再生位置が先頭でないときは、カードに「⏮ 止めて元の位置へ」を出す。
- 「とばす」は `Progress::skip`。とばしたミッションは次の候補から外れるが、あとで条件を満たせば達成になって経験値ももらえる。一覧の「戻す」(`Progress::retry`) で候補に戻せる。全部とばしても「全ミッション達成」にはならない。
- 一覧の「挑戦」は `Progress::focus`。えらんだミッションを `next()` がおすすめ順より先に返す。達成するか「とばす」とおすすめ順に戻る。えらんだことは保存しない (次に起動したときはおすすめ順)。
- 章の最後のミッションを達成すると、`Achievement::chapter_complete` が入り、お祝いが「第N章 クリア!」になって紙吹雪が2倍になる。基本編・応用編の最後のミッションなら `Achievement::part_complete` も入り、「基本編 クリア!」になる。

## ミッションの判定

UI 層は毎フレーム `Observation`(選択の有無、カメラの角度、最新の履歴の名前、計測・寸法の数、干渉している組の数、再生中か、保存済みか など)を作って渡すだけです。
`Progress::observe` は直前の `Observation` と比べて「変化したとき」だけ達成にします。

- 最初の観測は基準にするだけで、何も達成しない(起動直後の状態で勝手にクリアしない)。
- 見まわし: 3D ビューの上でマウスのボタンを押している間のヨー・ピッチの変化を足し、0.6 rad を超えたら達成。全体表示などの自動のカメラの動きは数えない。
- 編集: 履歴の名前が「◯◯ を編集」「◯◯ を追加」に変わったとき(ファイルの読み込みは数えない)。名前は `history.rs` が付ける。
- 干渉: 一度編集したあとで、干渉している組の数が増えたとき(サンプルに最初からある干渉は数えない)。
- 標準部品を置く: モデルの中の標準部品 (`NodeKind::Standard`) の数が増えたとき。
- 工程シミュレーション: `FlowRun` に結果 (`report`) が出たとき。
- 保存: ファイルに結びつき、未保存の変更がない状態になったとき。未保存かどうかは、ウィンドウのタイトルを更新するときに `ProjectState` が覚えておいた値を使う(モデルを比べ直さない)。
- 応用編: タイミングチャートのアクチュエータに割り当てた部品の数・ステップの数・センサーの数が増えたとき、安全パネルで非常停止を押すか遮光したとき (`SafetyState::manually_tripped`)、内蔵の模擬 PLC で運転し始めたとき (`Plc::simulated_running`)、ライン連携が動き始めたとき (`LineState::is_running`)、一人称で歩き始めたとき。「言葉でラインを組む」で置いた回数・ラダーや I/O 表を書き出した回数・動画を書き出し終えた回数は、それぞれ `ComposeUi`・`SequenceGen`・`Recorder` が数えていて、増えたときに達成にする。これらの値は `track_missions` の `ToolSignals` がまとめて集める。

経験値は 150 XP ごとに 1 レベル上がります。称号は `level_title` にあります。

## 設定ファイル

ミッションカードの表示・達成したミッション・とばしたミッション・経験値・ようこそ画面を閉じたかを `preferences.json` に保存します。変更があったフレームだけ書き出します。

| OS | 場所 |
| --- | --- |
| Windows | `%APPDATA%\plantwright\preferences.json` |
| macOS | `~/Library/Application Support/plantwright/preferences.json` |
| その他 | `$XDG_CONFIG_HOME/plantwright/preferences.json`(なければ `~/.config/plantwright/…`) |

```json
{
  "show_missions": true,
  "completed_missions": ["select_part", "orbit_view"],
  "skipped_missions": ["run_flow"],
  "xp": 100,
  "welcomed": true
}
```

ミッションは `key`(例: `select_part`)で保存するので、並び順を変えたり新しいミッションを足したりしても前の進み具合は残ります。知らない key と壊れた JSON は無視して標準の設定で始めます。以前の版が書いた `"theme"` も知らない項目として読み飛ばします。

## 演出

- お祝い: egui の前面の `Area` に「ミッション達成!」を出す。出るときは ease-out-back で少し大きくなり、最後の 0.5 秒でふわっと消える(3.2 秒)。
- 紙吹雪: `confetti(seed, count, colors)` が初速と回転をもつ破片を作り、`ConfettiPiece::at(t)` が重力つきの位置を返す。描画は前面のレイヤーに回転した四角形を描くだけ。レベルアップと全クリアでは2倍の量にする。
- マスコット: 立方体のキャラクターを egui の `Painter` で描く。ふだんはゆっくり上下し、4 秒ごとにまばたき、お祝い中は跳ねて目が「^ ^」になる。

## ミッションを足すには

1. `gamify.rs` の `MissionId` と `MISSIONS` に足す(`key` は保存に使うので後から変えない)。章・手順・キー・操作する場所も書く。章の途中に入れるときは並び順に気をつける。
2. 判定に要る値を `Observation` に足し、`Progress::observe` の `reached` に条件を書く。単体テストを足す。
3. `ui/playful.rs` の `track_missions` (道具の状態なら `ToolSignals::fill`) でその値を集める。
4. README の「ミッションで操作を覚える」を更新する。
