# 状態のエフェクトのしくみ

工程シミュレーションやライン連携を回している間、設備の状態を 3D ビューの光・煙・火花で見せます。
色分け (工程シミュレーションの「3D の色」) は部品を塗るだけなので、遠くからや小さく映っているときに気づきにくいことがあります。
エフェクトは部品より大きく光らせ、床に波紋を広げ、煙を上に昇らせるので、ライン全体を見渡していても止まった所がわかります。

## 何をどこに出すか

| きっかけ | 見た目 | 出す場所 |
| --- | --- | --- |
| 詰まり (工程の状態が `Blocked`) | 赤く脈打つ光、床に広がる赤い波紋 | 工程に結び付けた 3D の部品を包む球 |
| 故障 (`Down`) | 速く脈打つ赤い光、波紋、黒い煙 | 同上。煙は部品の上面の中心から |
| 人待ち (`NoOperator`) | ゆっくり点滅する黄色い光 | 同上 |
| 溶接中 (名前に「溶接」「ウェルド」「weld」を含む工程が `Working`) | ちらつく青白い光と火花 | 同上。火花は部品の上面の中心から |
| 安全停止 | 速く点滅する赤い光と波紋 | 停止させた安全機器の上 (リセットするまで) |
| 干渉 (タイミングチャートの再生中) | 小さな火花 | 干渉している部品どうしの交線の中心。はめあいなどで止まったまま重なっている部品に出し続けないよう、再生している間だけ出す |

工程の状態は工程シミュレーションの `Simulation::state_of` から読みます。工程シミュレーションのウィンドウで回しているときも、ライン連携で回しているときも同じです。
結果が今の工程モデルと合わなくなったら (`FlowRun::is_stale`) 出しません。部品を非表示にしたときも出しません。

溶接かどうかは今のところ工程の名前で見分けます。工程の設定に項目を足していないので、プロジェクトファイルの形式は変わりません。

## コードの置き場所

| 層 | 場所 | 中身 |
| --- | --- | --- |
| ドメイン | `cadsim_core::effects` | きっかけ (`Cue`) と見た目 (`Look`・`Glow`)、設定 (`EffectSettings`)、出す場所 (`Emitter`) の決め方 (`flow_emitters`・`safety_beacon`・`collision_point`) |
| ドメイン | `cadsim_core::effects::particles` | 煙と火花の粒 (`ParticleField`)。1 秒あたりの数だけ生み、重力・浮力・空気抵抗で動かし、寿命で消す |
| UI | `src/effects/mod.rs` | 毎フレーム状態を集めて粒を進め、光と煙の球・火花と波紋の線に写す |
| UI | `src/ui/menu.rs` | 表示メニューの「状態のエフェクト」 |

設定は `ViewSettings::effects` に持ちます (表示メニューのほかの切り替えと同じく、プロジェクトには保存しません)。

## 重くしないための工夫

- 粒の総数に上限 (`EffectSettings::max_particles`、既定 800) を設け、超えたら新しい粒を出しません。
- 1 フレームで進める時間を 0.1 秒までにし、止まっていたあとで一度に大量の粒が出ないようにしています。
- 火花と波紋はギズモの線で描きます。メッシュも材質も作りません。
- 光と煙は、1 つの球のメッシュを使い回す入れ物 (エンティティ) に載せ、要らない分は隠します。毎フレーム作り直しません。
- 光の材質はきっかけごとに 1 つで、脈打つ明るさは材質の色を書き換えて出します (同じきっかけの光は一緒に脈打ちます)。
  煙の材質は濃さを 8 段に分けて用意し、粒の濃さに近い段を選びます。粒ごとに材質を作りません。
- 光と煙は影を落としません (`NotShadowCaster`)。

## 毎回同じ動きにする

粒の乱数は種の決まった xorshift で、光のちらつきも時刻から決まる値です。
画面の自動確認 (`cargo ui-check`) は 1 フレーム = 1/60 秒で時計を進めるので、同じ場面では同じ粒の並びで撮れます。
