# ワーク搬送(投入口・コンベア・グリッパ・排出口)のしくみ

使い方は [README](../README.md) の「コンベアでワークを流し、チャックで掴んで運ぶ」を見てください。

## 置き場所

| 層 | 場所 | 内容 |
| --- | --- | --- |
| ドメイン | `crates/cadsim_core/src/conveyor/` | 設定 `ConveyorConfig`、計算 `ConveyorSim`、数 `Counts`、繰り返し再生をまたぐ時計 `CycleClock`、装置の動き(グリッパの開閉と、ワークを載せて動く部品)を受け取るトレイト `MachineMotion`。Bevy・egui・タイミングチャートに依存しない |

| アプリ | `src/conveyor/ui.rs` | 「ワーク搬送」ウィンドウ |

## 計算のしかた

`ConveyorSim` は時刻 0 から 1/240 秒刻みで進める決定的な計算です。毎刻み次の順で処理します。

1. **投入。** 投入口 `Source` は `interval` 秒ごとに(最初は時刻 0)ワークを出す。種類は `kinds` を順番に使い(空なら最初の種類)、`limit` 個で止まる。出す先がコンベアなら始端、`OnPart` なら投入口の部品の上面の中央。出す場所に他のワークがあれば空くまで待つ。
2. **搬送。** ワークは「ベルト始端からワーク後端までの距離 `s`」で持ち、先頭から順にベルト速度で進める。前のワークの後端(すき間はワーク長の 5%)やストッパで止まる。終端が排出のコンベアでは、終端から完全に出たワークを消して `Exit::Conveyor` として数える。
3. **把持 / 解放。** グリッパの状態(閉じているか、グリッパを運ぶ変換)を `MachineMotion::gripper_state` に聞く。閉じた刻みで TCP から `reach` 以内の最も近いワークを掴み、「運ぶ変換の逆 × ワークの位置」を相対位置 `Place::Held` として覚える。別のグリッパが掴んでいるワークも掴める(持ち替え)。開いた刻みで離し、次の順に置き場所を決める。
   - 真下にベルトがある(ワーク下面がベルト上面からワーク高さの半分以内)→ そのコンベアに載せ、ベルトの中心線に寄せる。
   - 真下に `MachineMotion::carriers` が返す部品の上面がある → `Place::Carried` としてその部品からの相対位置を覚え、一緒に動く(載せ替え)。
   - どちらでもない → その場に置く(`Place::Placed`)。
4. **追従。** `Held` / `Carried` のワークの位置を「運ぶ変換 × 相対位置」にする。
5. **排出口。** 排出口 `Sink` の部品の外接箱に触れた(ワーク寸法の 5% 以内)ワークを消して `Exit::Sink` として数える。掴まれているワークは数えない。

数 `Counts` は投入口ごとの投入数 `fed`、出口ごとの排出数 `discharged`、種類ごとの (投入, 排出) `by_kind` を持つ。仕掛数は `ConveyorSim::in_process`(残っているワークの数)。

前の時刻へシークしたときは 0 から計算し直します(`seek`)。設定・チャート・ベルトの形が変わったときもアプリ側で作り直します。

## タイミングチャートとのつなぎ

`ChartMotion` が次のように `MachineMotion` を実装します。

- チャックはシリンダ。値が 1(出端)になり切っていれば閉。
- 運ぶ変換は、チャックの「載せ先」アクチュエータの、親の動きも含めた変換(`motion::actuator_poses`)。載せ先がなければ動かない。
- ワークを載せて動く部品(`carriers`)は、部品が割り当てられたアクチュエータごとの、その部品の設計位置の外接箱をアクチュエータの変換で動かしたもの。
- `repeat: true` なら経過時刻をサイクルタイムで割った余りをチャート上の時刻にする。繰り返し再生で何サイクル目かは `CycleClock` が数える(再生中に時刻がサイクルの半分以上戻ったら次のサイクル、先頭で止めたら 0 に戻す)。

## センサーなどから使う

- ライン連携で工程の送り出しに使う投入口は、間隔ではなく工程から頼まれたときだけワークを出し、そのワークに荷札 `Work::tag` を付ける。しくみは [line.md](line.md) の「工程とコンベアの受け渡し」。
- 毎フレームのワークは `conveyor::WorkState::works()`。ワークの位置を使うシステムは `.after(ConveyorSet::Works)` で登録する。`Work::aabb()` でワールドの外接箱が取れる。
- 時刻表を作りながら任意の時刻のワークを知りたいときは、`ChartMotion { repeat: false, .. }` を渡した `ConveyorInputs` で `ConveyorSim::advance_to` を時刻順に呼ぶ。

## 単位

ベルト・投入口・排出口は割り当てた部品の設計位置での外接箱です。詰まりのすき間と「ベルトに載ったとみなす高さ」はワーク寸法に対する割合なので、mm でも m でも同じように動きます。
