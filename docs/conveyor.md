# ワーク搬送(コンベアとグリッパ)のしくみ

使い方は [README](../README.md) の「コンベアでワークを流し、チャックで掴んで運ぶ」を見てください。

## 置き場所

| 層 | 場所 | 内容 |
| --- | --- | --- |
| ドメイン | `crates/cadsim_core/src/conveyor/` | 設定 `ConveyorConfig`、計算 `ConveyorSim`、繰り返し再生をまたぐ時計 `CycleClock`、グリッパの動きを受け取るトレイト `GripperMotion`。Bevy・egui・タイミングチャートに依存しない |
| アプリ | `src/conveyor/mod.rs` | Bevy のプラグイン。`ChartGripperMotion`(タイミングチャートから `GripperMotion` を実装)、入力を集めて `ConveyorSim::seek` を呼び、ワークを表示用エンティティに写す |
| アプリ | `src/conveyor/ui.rs` | 「ワーク搬送」ウィンドウ |
| アプリ | `src/motion/demo.rs` | サンプル装置(供給コンベア → ガントリー → 排出コンベア) |

## 計算のしかた

`ConveyorSim` は時刻 0 から 1/240 秒刻みで進める決定的な計算です。毎刻み次の順で処理します。

1. **供給。** 供給ありのコンベアは、予定時刻になったら始端にワークを置く。始端が詰まっていれば空くまで待つ。
2. **搬送。** ワークは「ベルト始端からワーク後端までの距離 `s`」で持ち、先頭から順にベルト速度で進める。前のワークの後端(すき間はワーク長の 5%)やストッパで止まる。排出端から出たワークは消す。
3. **把持 / 解放。** グリッパの状態(閉じているか、グリッパを運ぶ変換)を `GripperMotion` に聞く。閉じた刻みで TCP から `reach` 以内の最も近いワークを掴み、「運ぶ変換の逆 × ワークの位置」を相対位置として覚える。開いた刻みで離し、真下にベルトがあれば(ワーク下面がベルト上面からワーク高さの半分以内)そのコンベアに載せてベルトの中心線に寄せる。
4. **追従。** 掴んでいるワークの位置を「運ぶ変換 × 相対位置」にする。

前の時刻へシークしたときは 0 から計算し直します(`seek`)。設定・チャート・ベルトの形が変わったときもアプリ側で作り直します。

## タイミングチャートとのつなぎ

`ChartGripperMotion` が次のように `GripperMotion` を実装します。

- チャックはシリンダ。値が 1(出端)になり切っていれば閉。
- 運ぶ変換は、チャックの「載せ先」アクチュエータの、親の動きも含めた変換(`motion::actuator_poses`)。載せ先がなければ動かない。
- `repeat: true` なら経過時刻をサイクルタイムで割った余りをチャート上の時刻にする。繰り返し再生で何サイクル目かは `CycleClock` が数える(再生中に時刻がサイクルの半分以上戻ったら次のサイクル、先頭で止めたら 0 に戻す)。

## センサーなどから使う

- 毎フレームのワークは `conveyor::WorkState::works()`。ワークの位置を使うシステムは `.after(ConveyorSet::Works)` で登録する。`Work::aabb()` でワールドの外接箱が取れる。
- 時刻表を作りながら任意の時刻のワークを知りたいときは、`ChartGripperMotion { repeat: false, .. }` を渡した `ConveyorInputs` で `ConveyorSim::advance_to` を時刻順に呼ぶ。

## 単位

ベルトは割り当てた部品の設計位置での外接箱です。詰まりのすき間と「ベルトに載ったとみなす高さ」はワーク寸法に対する割合なので、mm でも m でも同じように動きます。
