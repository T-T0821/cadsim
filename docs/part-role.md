# 部品の役割

部品を選んでプロパティの「この部品を…にする」を押し、3D ビューで矢印や点をドラッグして向き・長さ・速さを決める機能のしくみです。使い方は README の「部品に役割を付けて動かす」を見てください。

## どこに何があるか

| 場所 | 中身 |
| --- | --- |
| `crates/plantwright_core/src/part_role/model.rs` | 役割の種類 `RoleKind`、付いている行 `RoleRef`、編集中の写し `RoleBody`・`RoleDraft` |
| `crates/plantwright_core/src/part_role/assign.rs` | 部品の役割を探す (`roles_of`)、寸法から既定値で作る (`new_draft`)、書き込む (`apply`)、外す (`remove`)、足りない設定 (`issues`・`parts_with_issues`) |
| `crates/plantwright_core/src/part_role/tool.rs` | 3D の道具 `RoleTool`。つまみの位置、カーソルを落とす先 (`Constraint`)、ドラッグ・面のクリックから値を決める計算 |
| `src/features/part_role/panel.rs` | プロパティの「シミュレーションの役割」 |
| `src/features/part_role/systems.rs` | マウスとキー (Enter で確定、Esc で取り消し) |
| `src/features/part_role/view.rs` | 3D の矢印・点・動いた先の箱、値と案内の文字、黄色い「!」 |

## 役割の実体

役割は新しいデータを持たず、すでにある設定の行を部品の側から見たものです。

| 役割 | 行 | 部品との結びつき |
| --- | --- | --- |
| シリンダ・直動軸・回転テーブル | タイミングチャートのアクチュエータ | `parts` の最初の部品 |
| 光電・近接センサー | タイミングチャートのセンサー | `Sensor::part` (この機能で足した項目。検知には使わない) |
| コンベア・投入口・排出口 | ワーク搬送の設定 | それぞれの `part` |
| グリッパ | ワーク搬送の設定 | 開閉するシリンダ (`chuck`) が動かす最初の部品 |

## 下書きと確定

ボタンを押すと `new_draft` が部品の外接箱 (ワールド座標) と単位 (`units_per_mm`) から既定値を決めた写しを作ります。

- シリンダ: いちばん長い向きに、長さの半分のストローク
- 直動軸: いちばん長い向きに、長さだけ動ける範囲 (`limits`)
- 回転テーブル: 外接箱の中心を通る Y 軸
- コンベア: 水平の長い辺 (X か Z) の向きに 200 mm/s。ただし 1 秒で長さの半分を超えない
- センサー: +Z の面の中心から +Z へ、光電 300 mm・近接 20 mm
- グリッパ: 外接箱の下面の中心、掴める距離 20 mm。開閉するシリンダはその部品を動かすアクチュエータ (なければ作れない)

ドラッグや面のクリックは写しだけを変え、Enter の `apply` で初めてチャートとワーク搬送の設定に書きます。新しいシリンダには「出 → 戻」の 2 ステップを足します。チャートとワーク搬送の設定は TrackedDoc なので、確定は 1 件の履歴になり Ctrl+Z で戻ります。Esc は写しを捨てるだけなので、何も残りません。

## ドラッグの計算

つまみごとに、カーソルのレイを落とす先 (`Constraint`) を決めます。アプリ側はレイをそこへ落とした点を `RoleDraft::drag` に渡すだけです。

| つまみ | 落とす先 | 決まるもの |
| --- | --- | --- |
| シリンダ・直動軸の矢印の先 | 外接箱の中心を通る軸の直線 | 中心からの距離 − 半分の長さ = ストローク。中心より反対側なら逆向き |
| センサーの光の先 | 取り付け位置を通る軸の直線 | 距離 = 範囲。反対側なら逆向き |
| コンベアの矢印の先 | 上面の高さの水平面 | X と Z の大きい方を向きに、その長さ ÷ 1 秒 = 速さ |
| グリッパの掴む位置 / 掴める距離 | 点を通り画面に平行な面 | 位置 / 掴む位置からの距離 |
| 投入口の点 | 画面に平行な面 (線を描くだけ) | 離したときカーソルの下にある部品がコンベアなら、その出す先 |

面のクリックは、法線にいちばん近い軸とその符号を向きにします (穴あけの道具と同じ考え方)。

## 足りない設定の「!」

`parts_with_issues` が、部品に結びついた役割ごとに次を調べ、部品ごとにまとめます。

- シリンダのストロークが 0、アクチュエータがチャートのどのステップでも動かされず、ロボットの関節でもない
- センサーの範囲が 0、コンベアの速さが 0、投入口の間隔が 0
- グリッパの開閉するシリンダがない

アプリ側は部品の外接箱の上面の中心に、押せる「!」を出します。
