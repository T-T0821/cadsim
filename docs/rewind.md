# 巻き戻しと時間スライダーのしくみ

工程シミュレーションとライン連携は、回している途中の状態を記録しておき、時間スライダーで好きな時刻に戻せます。
使い方は README の「工程シミュレーションでスループットを見る」と「工程・AGV・安全機器をつないでラインとして動かす」にあります。

## 置き場所

| 層 | 場所 | 役割 |
| --- | --- | --- |
| ドメイン | `plantwright_core::timeline` | 時刻ごとの状態の写し `Timeline<S>`、決まった手順で進むシミュレーションのトレイト `Replay` |
| ドメイン | `plantwright_core::flow::rewind` | 工程シミュレーション (`Simulation`) の `Replay` 実装、写しの間隔の決め方、詰まり始めの探し方 (`jam_marks` / `previous_jam` / `next_jam`) |
| ドメイン | `plantwright_core::line::rewind` | ライン一式の写し `LineSnapshot` (受け渡しの状態・工程・AGV・コンベア・作業者の時計・チャートの再生位置) |
| UI | `src/features/flow/mod.rs` (`FlowRun::{advance_to, seek}`)、`src/features/flow/panel/mod.rs` (`time_slider`) | 工程シミュレーションのウィンドウのスライダーとボタン |
| UI | `src/features/line/mod.rs` (`LineState::{record, restore}`)、`src/features/line/panel.rs` (`time_slider`) | ライン連携のウィンドウのスライダーとボタン |

## 写しの取り方

`Timeline` は「時刻 → 状態の写し (`Clone`)」を時刻の早い順に持ちます。前の写しから決まった間隔がたつごとに写しを取り、数が上限を超えたら1つおきに捨てて間隔を倍にします (最初と最後の写しは残す)。長く回しても使うメモリは一定で、最初から最後までどこへでも戻れます。

| | 間隔 | 上限 |
| --- | --- | --- |
| 工程シミュレーション | 回す時間 ÷ 400 (8 時間なら 72 秒) | 512 個 |
| ライン連携 | ラインの時刻で 0.5 秒 | 1200 個 (10 分を超えると間隔が 1 秒、2 秒 … と広がる) |

## 戻し方

**工程シミュレーション** は乱数の種も状態に持っていて、同じ状態から進めれば同じ結果になります (`Replay`)。そこで `Timeline::seek` は、戻したい時刻の直前の写しを取り出し、そこから目的の時刻まで進め直します。写しの間の時刻にもぴったり戻せ、戻した時点から進めても同じ未来になるので、先の写しは捨てずに使います。⏩ 最後まで も写しを取りながら進めます (`advance_recording`)。

**ライン連携** は PLC の信号や画面の切り替え (運転・投入許可) で進み方が変わるので、進め直しはせず、いちばん近い前の写し (0.5 秒刻み) にそのまま戻します。戻した時点から再生を続けると、その先の写しを捨てて記録し直します (`truncate_after`)。戻す処理は毎フレームの `advance_line` の中で行い (`LineState::seek_to` に頼んでおく)、工程・AGV・コンベアのワーク・作業者の時計・チャートの再生位置を一度にそろえます。

## 詰まりの探し方

工程シミュレーションの推移 (`Sample`。回す時間を 240 に分けた各時刻の要素ごとの状態) を前から見て、「前の記録では詰まりでなく、次の記録で詰まり」になった要素がある所を詰まり始めとします。⏮ / ⏭ はその **前の記録の時刻** (詰まる直前) へ飛ぶので、そこから再生すると詰まっていく様子を見られます。
巻き戻している間も先の詰まりを探せるように、いちばん先まで回した写しの推移を使います。
