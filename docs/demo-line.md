# デモライン

`samples/demo_line.cadsim` は、ほとんどの機能を一度に見せるためのサンプルプロジェクトです。デモ動画の撮影や、起動直後のサンプルとして使います。

## 作り方

手で編集せず、`tools/make_demo_line.py` で生成します。寸法や教示点を変えたいときはスクリプトを直して作り直してください。

```sh
python3 tools/make_demo_line.py   # samples/demo_line.cadsim を書き出す
```

Python 3 の標準ライブラリだけで動きます。

## 中身

| まとまり | 内容 |
| --- | --- |
| ロボットセル | 箱で組んだ 4 軸の多関節ロボット(J1〜J4 は回転テーブル、ハンドはエアシリンダ)、移載台 |
| 搬送 | 供給・排出のベルトコンベア(標準部品)、投入シュート、排出箱、光電センサー 2 つ、整列シリンダ |
| 制御盤まわり | 制御盤・PLC・電源・リモート I/O・リレー、操作台と押しボタン、表示灯ポール |
| 周辺設備 | 部品棚、検査台とカメラ、出荷パレット、AGV の充電ステーション |
| タイミングチャート | ピック上へ → 下降 → 把持 → 上昇 → プレース上へ → 下降 → 解放 → 上昇・整列 → 待機位置へ(1 サイクル 6.00 秒)。把持の確認はハンドに付けたセンサーのインターロック |
| コンベア | ハウジングとカバーを 6.6 秒ごとに流し、ロボットのハンドで掴む |
| 安全・フロア | 安全柵、前面のライトカーテン、非常停止、背面のエリアセンサー、作業者 2 人、AGV 2 台と経路 |
| 工程 | 部品投入 → ロボット移載(チャートを起動)→ 排出コンベア(AGV で搬送)→ 外観検査 → 出荷。作業者 3 人とシフト 2 つ |
| 注記 | 距離寸法 1 つ、メモ 2 つ、ケーブル 2 本 |

## ロボットの動かし方について

設計姿勢(腕がまっすぐ上を向いた姿勢)は特異姿勢なので、そこから逆運動学で教示点へ動かすと解けないことがあります。
そのため大きな移動は、スクリプトの `arm_pose()` で解析的に求めた関節角を関節動作として書いています。
直線移動(教示点への Linear)を使うのは、ピック・プレース位置での上下の動きだけです。
