# 形状の簡略化(小さな穴とフィレットを消す)

大規模アセンブリでは、ボルト穴やフィレット(角の丸み)が三角形の大半を占めます。配置やレイアウトの確認には要らないので、「表示 → 小さな穴とフィレットを省略」をオンにすると、取り込んだ部品の表示用メッシュからだけ消します。

- 計算は `src/defeature.rs`(Bevy に依存しない)。表示への組み込みは `src/viewport.rs` の `defeature_shapes`。
- 対象は STEP から読み込んだ部品(B-rep を持つもの)。glTF / OBJ / STL などのメッシュで読み込んだ部品、箱、負荷テスト用シーンの部品は B-rep が無いので変わりません。
- 干渉チェックは元の形のまま行います(`SimBody` のメッシュは差し替えない)。クリックでの選択・距離計測・寸法は、表示している(簡略化した)形に当たります。

## 穴

1. 平面の面にある内側の輪郭(穴の縁)のうち、外接箱の最大辺が「穴の直径」以下のものを集める。いちばん大きい輪郭は外周とみなす。
2. 縁の辺から、縁のある平面を越えずに隣の面をたどる(幅優先、64 面まで)。貫通穴なら反対側の平面の縁で止まり、止まり穴なら底の面までが穴になる。縁を通らずに縁のある平面へ着いたら穴ではない。
3. たどった面の三角形がすべて縁の中心を通る軸から「穴の直径」以内にあり、法線が軸の方を向いている(凹)ものだけを穴とする。ボスやピン(凸)は残す。法線の向きは、シェル全体の符号付き体積で外向きかどうかを確かめてから判定する。
4. 穴の面を B-rep から外し、縁の輪郭を平面の境界から外してテッセレーションし直す。平面は truck が穴なしで張り直す。

## フィレット

1. 平面でない面のうち、隣の平面のちょうど2つに接しているもの(曲面の頂点法線と平面の法線がほぼ同じ向き)を候補にする。頂点法線は truck が付けた曲面の正確な法線なので、粗いテッセレーションでも判定がぶれない。
2. 2つの平面の交線から曲面のいちばん遠い点までの距離 d と、2平面の法線のなす角 α から半径を r = d / tan(α/2) と見積もり、「フィレットの半径」以下なら消す。2つの平面が平行(長穴の端の半円など)なら消さない。
3. フィレットの縁の点を交線に移す。縁の点は両側の平面のメッシュと同じ座標なので、平面のメッシュが交線まで延びて角が尖る。端の面(断面)のメッシュは円弧の点が角の1点に集まり、つぶれた三角形は表示メッシュを作るときに捨てる。
4. フィレットが集まる角の小さな曲面(まわりが消すフィレットか平面だけのもの)も一緒に消す。
5. 稜線は、消した面どうしの境目と消した穴の縁を捨て、残りは点を移す。

## 面の番号と選択

簡略化した面の番号は、簡略化していない表示メッシュ(`ImportedShape::mesh`)と同じ番号にそろえています(`PartMesh::with_face_ids`)。テッセレーションできなかった面は表示に入らないので、元の B-rep の面の並びから詰めた番号にします。オン・オフを切り替えても、クリックで選んだ面はそのまま同じ面を指します。

## 裏での計算と差し替え

- 形状(同じ製品の部品で共有している形)ごとに、Bevy の `AsyncComputeTaskPool` で計算する。結果が出たものから、その形状を使う部品すべての表示を差し替える。
- しきい値を変えたら、前の条件の計算はやめて計算し直す。新しい結果が出るまでは前の結果を表示しておく。
- オフにすると元の表示に戻す。結果は捨てずに持っておくので、同じ条件でオンに戻すとすぐ反映される。
- 画面上で小さい部品の粗いメッシュ(LOD)は、簡略化した形からも作る。

## テスト

`src/defeature.rs` の単体テストで次を確かめています。

- 板の小さな貫通穴が埋まり、直方体の体積になる。大きな穴は残る。
- 1つの角を丸めた棒のフィレットが消え、丸める前の体積に戻る。半径の大きいフィレットは残る。
- STEP に書き出して読み込み直した部品(表示と同じ経路)で、穴とフィレットの数、三角形の減り方、面の番号が表示と合うこと、小さな穴の位置にレイが当たるようになること。
