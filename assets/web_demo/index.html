軽いビューア GitHub ライセンス
このデモでできること・できないこと
  • できる: デスクトップ版と同じアプリで、本物のロボット (UR5e + Robotiq 2F-85) のピック & プレースを動かす・カメラを回す・部品を選んで動かす・タイミングチャートの再生・干渉チェック・形状カーネル (SMLib) を使ったモデリング・メニューの「サンプル」から別のサンプルを開く
  • できない: ファイルを開く・保存する・取り込む・書き出す (プロジェクト、STEP・glTF、図面、Excel、動画)
  • できない: 外部の PLC との通信 (Modbus TCP・SLMP・OPC UA)、実機ロボットとの接続、レビューの共有、生成 AI への問い合わせ
  • ページを閉じると作業は消えます。すべての機能はデスクトップ版で使えます。
  • 使っているソフトウェアのライセンスはアプリの「ヘルプ → ライセンス」にあります。ブラウザ版はこのほか wasi-libc と LLVM libc++ を含みます。
